# 📘 주간학습안내를 읽고 오늘의 수업자료를 보내는 에이전트 만들기

## [이번 챕터에서는]

아침마다 교사는 주간학습안내에서 오늘 시간표를 확인하고, 수업에 쓸 자료를 다시 검색합니다. 이 챕터에서는 이 과정을 Codex에게 맡기는 에이전트를 처음부터 만들어 봅니다.

에이전트가 할 일은 간단합니다. 주간학습안내를 읽고, 오늘 수업을 확인하고, 인디스쿨에서 관련 자료를 찾고, 링크와 한 줄 요약을 카카오톡 ‘나와의 채팅’으로 보내는 것입니다.

학교 홈페이지에 주안이 올라오는 경우와 주안을 컴퓨터 폴더에 직접 넣는 경우를 모두 다룹니다. 마지막에는 매일 오전 8시 40분에 자동으로 실행하는 방법도 연결합니다.

이 원고는 완성품 설치 설명서가 아닙니다. 독자가 Codex와 대화하면서 같은 에이전트를 직접 만드는 제작 실습 원고입니다.

## [한눈에 보기]

### 준비물

- Codex가 설치된 컴퓨터
- 학교 주간학습안내 파일 또는 학교 홈페이지 주소
- 인디스쿨 교사 계정
- 카카오 계정과 Kakao Developers 앱
- 테스트할 과거 주간학습안내 한 개

### 완성되는 흐름

```text
규칙 정하기
   ↓
파일과 Skill 뼈대 만들기
   ↓
주간학습안내 읽는 방법 정하기
   ↓
인디스쿨 로그인 한 번 저장하기
   ↓
카카오톡 ‘나와의 채팅’ 연결하기
   ↓
과거 주안으로 테스트하고 규칙 고치기
```

### 먼저 알아둘 말

Skill은 에이전트가 지켜야 할 작업 규칙입니다. 예를 들면 “체육과 영어는 제외한다”, “모를 때는 확인 필요라고 알린다” 같은 내용입니다.

Runtime은 실제로 파일을 읽고 브라우저를 움직이는 프로그램입니다. Script는 설치나 실행을 한 번에 처리해 주는 버튼 같은 파일입니다.

이 프로젝트는 기본적으로 Skill과 로컬 프로그램을 묶어 만드는 개인용 자동화입니다. 여러 사람이 공동으로 사용하는 서버를 만드는 MCP 프로젝트와는 다릅니다. 주간학습안내가 이미지일 때만 OpenAI API 키를 선택적으로 사용할 수 있고, HWP·HWPX 파일은 별도 키 없이 읽도록 만들 수 있습니다.

## [미리 보기]

완성된 에이전트는 다음처럼 움직입니다.

1. 오늘 날짜가 포함된 주간학습안내를 찾습니다.
2. 6학년 2반의 오늘 시간표를 확인합니다.
3. 체육·영어를 제외하고 오늘 수업의 차시명을 찾습니다.
4. 차시명에서 검색어와 꼭 확인할 단어를 나눕니다.
5. 인디스쿨 6학년 게시판에서 인기순으로 자료를 찾습니다.
6. 제목과 본문을 확인해 다른 단원 자료를 걸러냅니다.
7. 과목, 검색어, 제목, 링크, 한 줄 요약만 카카오톡으로 보냅니다.

## [실습하기]

### Step 1. 규칙 설계하기

#### 무엇을 하나요?

Codex에게 일을 시키기 전에, 에이전트가 지켜야 할 약속을 먼저 씁니다. 이 약속이 나중에 Skill 파일의 내용이 됩니다.

#### 왜 필요한가요?

“오늘 자료를 찾아 줘”라고만 하면 에이전트가 인기만 많은 다른 단원의 자료를 고를 수 있습니다. 검색 대상, 제외할 과목, 모를 때의 처리 방법을 먼저 정해야 결과를 믿을 수 있습니다.

#### 그대로 해보기

Codex 새 대화에 아래 내용을 붙여넣고 대괄호만 바꿉니다.

```text
교사용 ‘주간학습안내 → 인디스쿨 수업자료 → 카카오톡’ 에이전트를 만들고 싶어.

내 설정:
- 학교 홈페이지: [주소 또는 없음]
- 학년과 반: [예: 6학년 2반]
- 검색하지 않을 과목: [예: 체육, 영어]
- 발송 시각: [예: 매일 오전 8시 40분]
- 시간대: Asia/Seoul

먼저 코드를 만들지 말고, 에이전트가 지킬 규칙을 쉬운 말로 정리해줘.
반드시 포함할 내용은 다음과 같아.

1. 오늘 날짜와 우리 반의 1~6교시를 먼저 확인한다.
2. 월요일부터 오늘까지 과목이 나온 횟수와 학습내용 표의 같은 순번을 연결한다.
3. 차시명을 확실히 읽지 못하면 추측하지 않고 ‘확인 필요’라고 표시한다.
4. 인디스쿨 자료는 게시글 제목과 차시의 관련성을 확인한다.
5. 자료 파일을 복사하지 않고 게시글 링크와 짧은 요약만 보낸다.
6. 검색어와 찾지 못한 이유를 실행 기록에 남긴다.

규칙을 만든 뒤 내가 확인할 수 있도록 ‘정상 처리’와 ‘멈춰야 하는 경우’를 나누어 보여줘.
```

Codex가 만든 규칙에서 학교명이나 6학년 2반이 코드에 고정되어 있지 않은지 확인합니다. 다른 학교에서도 설정값만 바꾸어 사용할 수 있어야 합니다.

> [꿀팁 더하기] 한 글자라도 확실하지 않으면 자료를 억지로 보내지 않는다는 규칙을 처음부터 넣으세요. “확인 필요”라는 메시지가 잘못된 자료보다 안전합니다.

### Step 2. 파일 및 Skill 구조 설계하기

#### 무엇을 하나요?

에이전트를 여러 파일로 나눌 설계도를 만듭니다. Codex에게 먼저 폴더와 파일의 역할을 보여 달라고 요청한 뒤, 괜찮다고 확인하고 코드를 만들게 합니다.

#### 왜 필요한가요?

파일을 한 개에 모두 넣으면 나중에 검색 규칙 하나를 고치기도 어렵습니다. 규칙은 Skill에, 실제 실행은 runtime에, 설치와 예약 실행은 scripts에 나누면 초보자도 문제가 생긴 위치를 찾기 쉽습니다.

설정과 비밀값도 이 단계에서 함께 설계합니다. `.env.example`에는 필요한 설정 이름과 예시만 적고 실제 API 키는 넣지 않습니다. 사용자가 입력한 진짜 값은 프로젝트 폴더가 아니라 `%LOCALAPPDATA%\LessonAgent\config\.env`에 `setup.ps1`이 자동으로 저장합니다. `.gitignore`는 이 파일이 GitHub에 올라가지 않도록 막습니다.

#### 그대로 해보기

```text
앞에서 정한 규칙을 바탕으로 아래 구조의 프로젝트 설계도를 만들어줘.
아직 코드는 쓰지 말고 각 파일이 무슨 일을 하는지만 쉬운 말로 설명해줘.

indischool-daily-lesson-agent/
├── .codex-plugin/plugin.json
├── .env.example
├── .gitignore
├── README.md
├── docs/초보자용-설치안내.md
├── docs/초보자용-제작원고.md
├── skills/indischool-daily-lesson-agent/SKILL.md
├── runtime/pyproject.toml
├── runtime/src/lesson_agent/config.py
├── runtime/src/lesson_agent/weekly_plan.py
├── runtime/src/lesson_agent/indischool.py
├── runtime/src/lesson_agent/kakao.py
├── runtime/src/lesson_agent/message.py
├── runtime/src/lesson_agent/cli.py
├── scripts/setup.ps1
├── scripts/start-indischool-session.cmd
├── scripts/run.ps1
├── scripts/install-task.ps1
└── scripts/remove-task.ps1

설정 파일도 처음부터 포함해줘.
- `.env.example`에는 설정 이름과 빈 예시만 넣고 비밀값은 넣지 않는다.
- `.gitignore`에는 `.env`를 넣어 실제 설정 파일이 GitHub에 올라가지 않게 한다.
- `setup.ps1`이 학교 정보와 API 키를 질문하고 `%LOCALAPPDATA%\LessonAgent\config\.env`에 저장한다.
- `config.py`는 이 로컬 `.env`만 읽고, 코드 안에는 키를 적지 않는다.

모든 학교명, 학년, 반, 전담 과목, 발송 시각은 설정값으로 입력받게 해줘.
계획과 파일 역할만 먼저 보여주고 내가 ‘진행해’라고 답한 뒤에 코드를 작성해줘.
```

파일 역할은 다음처럼 기억하면 됩니다.

- `SKILL.md`: 에이전트가 지킬 규칙
- `config.py`: 학교·학년·반·시간·폴더를 저장하는 곳
- `weekly_plan.py`: HWP·HWPX·이미지에서 주안을 읽는 곳
- `indischool.py`: 인디스쿨 게시판을 탐색하는 곳
- `kakao.py`: 카카오톡으로 보내는 곳
- `message.py`: 메시지 모양을 정하는 곳
- `scripts`: 설치·로그인·테스트·예약 실행을 위한 버튼
- `.env.example`: 필요한 설정 이름을 보여 주는 안전한 예시 파일
- `.env`: 실제 설정값이 들어가며 `setup.ps1`이 로컬 폴더에 만드는 비공개 파일
- `.gitignore`: `.env`가 GitHub에 올라가지 않도록 막는 목록

Codex가 파일 구조를 보여 주면 “이 구조와 역할이 맞아. 진행해”라고 답합니다. 한 번에 전체 코드를 만들지 말고, 파일이 하나씩 만들어지는지 확인합니다.

### Step 3. 주간학습안내 처리 방법 설정하기

#### 무엇을 하나요?

주간학습안내를 어디서 가져올지, 표를 어떻게 읽을지, 차시명을 어떤 검색어로 바꿀지 정합니다.

#### 왜 필요한가요?

학교마다 주안 위치와 파일 형식이 다릅니다. 어떤 학교는 홈페이지에 HWP를 올리고, 어떤 학교는 교사가 파일을 컴퓨터에 저장합니다. 이 차이를 설정으로 만들어 두어야 다른 학교에서도 다시 코드를 만들지 않고 사용할 수 있습니다.

#### 3-1. 주안을 가져오는 방법 고르기

Codex에 다음을 요청합니다.

```text
주간학습안내 입력 방법을 web과 local 두 가지로 만들어줘.

web 방식:
- 설정한 학교 홈페이지에서 오늘 날짜가 포함된 주간안내 게시물을 찾는다.
- HWP, HWPX, JPG, PNG, WEBP 첨부파일을 읽는다.

local 방식:
- %LOCALAPPDATA%\\LessonAgent\\plans 폴더에 파일을 계속 추가한다.
- 2026-08-17_주간학습안내.hwpx처럼 날짜가 하나 있으면 그 날짜 자료로 본다.
- 2026-08-24_2026-08-28_주간학습안내.hwp처럼 날짜가 두 개 있으면 그 기간 자료로 본다.
- 오늘 날짜가 들어 있는 파일만 고르고 원본은 삭제하거나 이동하지 않는다.

LESSON_AGENT_PLAN_SOURCE=web|local 설정값으로 두 방식을 선택하게 해줘.
```

로컬 방식은 기존 파일을 지우지 않고 계속 추가하는 방식입니다. 지난 날짜 파일이 남아 있으면 같은 오류를 다시 테스트할 수 있습니다.

#### 3-2. 주안에서 오늘 수업 찾기

다음 규칙을 그대로 요청합니다.

```text
주간학습안내를 읽을 때 다음 순서로 처리해줘.

1. 먼저 문서의 날짜 범위가 오늘을 포함하는지 확인한다.
2. 우리 반의 시간표에서 오늘 요일 1~6교시를 읽는다.
3. 월요일부터 오늘의 해당 교시까지 과목별 등장 횟수를 센다.
4. 학습내용 표에서 그 과목의 같은 순번 행을 찾는다.
5. 원본을 확대해 날짜, 반, 시간표, 차시명을 두 번 대조한다.
6. 한 글자라도 확신하지 못하면 그 과목만 ‘확인 필요’로 남긴다.
7. 체육과 영어처럼 제외 과목은 검색하지 않는다.
```

예를 들어 금요일 수학이 그 주의 일곱 번째 수학 시간이라면 학습내용 표의 일곱 번째 수학 행을 찾아야 합니다. 금요일이라는 이유로 표의 마지막 줄을 고르면 안 됩니다.

#### 3-3. 차시명을 검색어로 바꾸기

검색창에 차시명 전체를 넣으면 다른 단원의 자료가 섞일 수 있습니다. 중심 검색어와 꼭 확인할 단어를 나누어 달라고 요청합니다.

```text
차시명을 분석해 ‘검색어’와 ‘필수 확인어’를 나누는 규칙을 만들어줘.

- 국어 읽기·쓰기: 활동 동사와 (1/2) 같은 차시 수를 빼고 핵심 명사를 붙인다.
  예: ‘견학 기록문 읽기 (1/2)’ → 검색어 ‘견학기록문’
- 국어·수학의 ‘마무리하기·복습·총정리·스스로 하기’:
  주안의 단원명을 찾아 ‘단원명 복습’, ‘단원명 총정리’, ‘단원명 마무리’를 각각 만든다.
- 수학·과학: 중심 개념과 보조 핵심어를 나눈다.
  예: ‘소수의 나눗셈을 자연수의 나눗셈과 비교해 볼까요’ → 검색어 ‘소수의 나눗셈’, 필수 확인어 ‘자연수’
- 사회·도덕: 개념어와 행동어를 나눈다.
  예: ‘기후변화에 대응하는 우리의 실천’ → 검색어 ‘기후변화’, 필수 확인어 ‘대응’ 또는 ‘실천’
- 음악: 차시 수를 뺀 노래명·활동명 전체를 검색한다.
- 미술: 연차시의 내용이 다르면 검색어를 따로 만들고, 관련 자료 2개와 최근 인기글 3개를 찾는다.

검색어와 필수 확인어를 실행 기록에 남겨줘.
```

### Step 4. 인디스쿨 로그인 세션 설정하기

#### 무엇을 하나요?

전용 Chrome 창에서 인디스쿨에 한 번 로그인하고, 그 로그인 상태를 저장해 다음 실행부터 다시 로그인하지 않도록 합니다.

#### 왜 필요한가요?

자동 실행 시간에는 사람이 로그인 창을 지켜볼 수 없습니다. 브라우저 프로필을 저장해 두면 쿠키와 로그인 상태를 계속 사용할 수 있습니다. 단, 이 프로필을 OneDrive 안에 두면 Chrome이 만드는 수천 개의 임시 파일 때문에 OneDrive 삭제 경고가 뜰 수 있으므로 반드시 로컬 경로를 사용합니다.

#### 그대로 해보기

```text
인디스쿨 로그인 세션을 저장하고 다시 사용하는 기능을 만들어줘.

1. 프로필 경로는 %LOCALAPPDATA%\\LessonAgent\\indischool-profile로 고정한다.
2. 경로에 OneDrive가 들어 있으면 실행하지 않는다.
3. scripts/start-indischool-session.cmd가 아래 옵션으로 Chrome을 열게 한다.
   --remote-debugging-address=127.0.0.1
   --remote-debugging-port=9222
   --user-data-dir="%LOCALAPPDATA%\\LessonAgent\\indischool-profile"
   https://indischool.com/
4. 첫 실행 때만 사용자가 직접 로그인한다.
5. 실제 검색 때는 새 Chrome을 열지 말고
   Playwright connect_over_cdp("http://127.0.0.1:9222")로 열린 Chrome에 연결한다.
6. /login 화면이 보이면 session_expired라고 기록하고 재로그인을 안내한다.
7. 세션이 정상일 때는 다시 로그인하라고 묻지 않는다.
```

이제 `start-indischool-session.cmd`를 실행하고 전용 Chrome 창에서 직접 로그인합니다. 로그인 후 창을 닫지 않고 최소화해 두면 됩니다.

매번 로그인하라는 메시지가 나오면 다음 세 가지를 확인합니다.

- 전용 Chrome 창이 실행 중인가요?
- 같은 `indischool-profile` 폴더로 실행했나요?
- 인디스쿨 세션이 실제로 만료된 것은 아닌가요?

### Step 5. 카카오톡 연결하기

#### 무엇을 하나요?

에이전트가 찾은 결과를 카카오톡 ‘나와의 채팅’으로 보내도록 연결합니다.

#### 왜 필요한가요?

검색 결과를 매번 컴퓨터에서 확인하지 않고 휴대폰에서 바로 보려면 메시지 전송 통로가 필요합니다. 카카오 인증은 인디스쿨 인증과 별개이므로 한 번 따로 연결해야 합니다.

#### 그대로 해보기

먼저 Kakao Developers에서 앱을 만들고 카카오 로그인을 켭니다. Redirect URI에는 다음 주소를 등록합니다.

```text
http://localhost:8765/callback
```

그다음 Codex에 요청합니다.

```text
Kakao Developers REST API로 ‘나와의 채팅’에 메시지를 보내는 기능을 만들어줘.

- REST API 키와 Redirect URI는 `%LOCALAPPDATA%\LessonAgent\config\.env`에서 읽는다.
- setup-kakao 명령으로 카카오 로그인과 토큰 발급을 한 번 진행한다.
- access token과 refresh token은 `.env`에 쓰지 말고 Windows 자격 증명 저장소(keyring)에 저장한다.
- TestKakao 명령으로 실제 자료 검색 없이 시험 메시지를 보낸다.
- 메시지는 아래 항목만 사용한다.
  📚 과목:
  🔎 검색어:
  📝 제목:
  🔗 링크:
  💡 핵심요약:
  ⚠ 확인사항: 필요한 경우만
- API 키, 토큰, 쿠키는 화면과 로그와 GitHub에 출력하지 않는다.
```

사용자는 `.env` 파일을 직접 편집하지 않아도 됩니다. 처음 설치할 때 `setup.ps1`이 필요한 값을 질문하고, `setup-kakao`가 토큰을 안전한 로컬 저장소에 저장합니다.

시험 메시지가 도착하면 카카오 연결은 끝난 것입니다. 시험 메시지가 오지 않으면 인디스쿨 검색 문제와 섞지 말고 Kakao Developers 설정과 토큰부터 확인합니다.

### Step 6. 테스트 발송 및 규칙 수정하기

#### 무엇을 하나요?

이미 수업이 끝난 과거 주간학습안내로 먼저 시험합니다. 화면에 결과만 보여 주는 DryRun, 카카오 시험 메시지, 실제 자료 발송 순서로 확인한 뒤 매일 실행을 등록합니다.

#### 왜 필요한가요?

오늘 자료로 처음 시험하면 정답을 비교하기 어렵습니다. 과거 주안은 교사가 시간표와 차시를 알고 있으므로 잘못 읽은 부분을 바로 찾을 수 있습니다. 이 단계의 목표는 “실행됨”이 아니라 “다른 단원 자료를 보내지 않음”입니다.

#### 6-1. DryRun으로 먼저 확인하기

Codex에게 다음처럼 요청합니다. 사용자가 PowerShell 명령어를 직접 외울 필요는 없습니다.

```text
2026년 6월 26일의 과거 주간학습안내로 시험해줘.
카카오톡으로는 보내지 말고, DryRun 결과만 보여줘.
날짜 범위, 우리 반 시간표, 과목별 누적 순번, 확정 차시명,
실제 검색어, 필수 확인어, 제목 필터 결과, 검색 실패 이유를 순서대로 보여줘.
```

화면에서 다음을 순서대로 확인합니다.

- 날짜 범위가 맞는가?
- 우리 반과 오늘 시간표가 맞는가?
- 과목별 누적 순번과 차시명이 맞는가?
- 검색어와 필수 확인어가 빠짐없이 나왔는가?
- 제목에 다른 단원 자료가 섞이지 않았는가?
- 찾지 못한 과목에 실제 검색어와 이유가 표시되는가?

#### 6-2. 실제 시험 발송하기

DryRun 결과가 맞으면 Codex에게 실제 카카오톡 시험 발송을 요청합니다.

```text
방금 확인한 2026년 6월 26일 결과를 카카오톡 ‘나와의 채팅’으로 시험 발송해줘.
메시지는 과목, 검색어, 제목, 링크, 핵심요약 한 문장만 사용해줘.
```

메시지는 과목, 검색어, 제목, 링크, 핵심요약만 간단히 보여야 합니다. 자료가 부족하다고 관련 없는 자료를 채우지 말고 `⚠ 확인사항:`으로 이유를 보냅니다.

#### 6-3. 매일 오전 실행 등록하기

```text
이 에이전트를 Windows 작업 스케줄러에 등록해줘.
매일 오전 8시 40분에 실행하고, 컴퓨터가 켜져 있지 않으면 다음 로그인 때 실행하도록 설정해줘.
등록한 작업 이름과 실행 조건을 보여줘.
```

Codex가 내부적으로 `install-task.ps1`을 실행할 수 있지만, 사용자는 명령어 대신 위 요청만 하면 됩니다. 컴퓨터가 켜져 있고 인터넷과 전용 Chrome이 준비되어 있어야 합니다. 예약을 없애고 싶을 때도 Codex에게 다음처럼 요청합니다.

```text
이 에이전트의 Windows 예약 실행을 해제해줘.
파일과 로그인 정보는 삭제하지 말고 예약 작업만 제거해줘.
```

#### 6-4. 오류를 규칙으로 고치기

잘못된 자료가 나오면 날짜별 예외를 추가하지 않습니다. Codex에 다음처럼 요청합니다.

```text
방금 테스트 결과를 판독 오류, 누적 순번 오류, 검색어 생성 오류,
제목 필터 오류, 본문 확인 오류, 로그인 세션 오류 중 하나로 분류해줘.
이번 날짜에만 적용되는 예외는 만들지 말고, 같은 유형의 차시와 다른 학교에도 적용되는 규칙으로 고쳐줘.
수정 전후의 차시명, 검색어, 필수 확인어, 제목 필터를 보여주고
같은 과거 주안으로 다시 DryRun해줘.
```

## [실전 활용하기]

이제 학교 홈페이지 주소, 학년, 반, 제외 과목만 바꾸면 다른 교사도 같은 방식으로 에이전트를 만들 수 있습니다. 주안이 홈페이지에 올라오지 않는 학교는 `plans` 폴더에 날짜가 들어간 파일을 계속 추가하면 됩니다.

인디스쿨 운영진의 허가와 이용약관을 먼저 확인합니다. 허가 전에는 게시판 자동 탐색을 켜지 않고, 에이전트가 검색어와 게시판 링크만 보내 사용자가 직접 검색하는 방식으로 운영할 수 있습니다. 자료 파일 자체를 복사하지 않고 허용된 게시글 링크와 짧은 요약만 제공합니다.

직접 만들지 않고 완성품을 활용하려는 사람은 GitHub 저장소에서 **Code → Download ZIP**을 선택합니다. 설치만 필요한 사람을 위한 안내는 저장소의 `README.md`와 `docs/초보자용-설치안내.md`에 따로 있습니다.
