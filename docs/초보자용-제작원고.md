# 📘 주간학습안내를 읽고 인디스쿨 자료를 보내는 에이전트 만들기

## [이번 챕터에서는]

매일 아침 주간학습안내를 확인하고, 오늘 수업에 필요한 인디스쿨 자료를 찾아 카카오톡 ‘나와의 채팅’으로 보내는 에이전트를 만들어 봅니다. 이 원고는 완성 프로그램의 설치 설명서가 아니라, **교사가 같은 에이전트를 직접 제작하는 과정**을 6단계로 안내합니다.

학교 홈페이지에 주간안내가 올라오는 경우와, 홈페이지에 올라오지 않아 컴퓨터의 폴더에 파일을 계속 추가하는 경우를 모두 다룹니다. 마지막에는 직접 만들지 않고 완성품만 활용하려는 사람을 위해 GitHub 다운로드 방법도 짧게 안내합니다.

## [실습하기]

### Step 1. 에이전트가 지킬 규칙 작성하기

Codex에 바로 “만들어 줘”라고 하기 전에, 에이전트가 무엇을 읽고 언제 멈출지 먼저 적습니다. 다음 문장을 메모장에 복사해 자신의 학교 상황에 맞게 고쳐 보세요.

```text
사용자가 설정한 학교·학년·반의 주간학습안내를 확인한다.
오늘 날짜와 해당 반의 1~6교시를 먼저 확정한다.
날짜·시간표·차시명을 확신하지 못하면 추측하지 말고 확인 필요로 표시한다.
체육·영어 등 사용자가 지정한 전담 과목은 제외한다.
차시명에서 과목별 핵심 검색어를 만들고 게시글 제목의 핵심어 일치를 우선한다.
자료 파일 자체를 복사하지 않고 허용된 게시글 링크와 한 줄 요약만 보낸다.
카카오 메시지는 과목·검색어·제목·링크·핵심요약만 표시한다.
```

이 규칙은 에이전트의 설계도입니다. 나중에 엉뚱한 단원의 자료가 섞이면 검색어 규칙과 제목 필터를 이 부분부터 고칩니다.

> [꿀팁 더하기] ‘정확하지 않으면 보내지 않는다’는 규칙을 처음부터 넣으세요. 차시명 한 글자를 추측해서 검색하는 것보다, 확인 필요를 표시하는 것이 안전합니다.

### Step 2. Codex에 Skill의 뼈대 요청하기

Codex에서 새 대화를 열고 다음 요청문을 그대로 붙여넣습니다. 괄호 안의 학교·학년·반·전담 과목만 바꿉니다.

```text
교사용 주간학습안내 자료 추천 에이전트를 Codex Skill로 만들어줘.

설정값:
- 학교: (학교 이름과 홈페이지 주소)
- 학년·반: (예: 6학년 2반)
- 제외 과목: (예: 체육, 영어)
- 발송 시각: (예: 매일 오전 8시 40분)

필수 기능:
1. 학교 홈페이지 방식과 날짜가 포함된 로컬 파일 누적 방식을 모두 지원한다.
2. 주간안내의 날짜·학급·교시·차시명을 두 번 확인하고, 확신이 없으면 확인 필요로 표시한다.
3. 과목별 차시명에서 핵심 검색어와 보조 핵심어를 자동으로 만든다.
4. 인디스쿨 게시글은 제목에 핵심어가 모두 있는 자료를 우선한다.
5. Kakao REST API로 나와의 채팅에 과목·검색어·제목·링크·한 줄 요약을 보낸다.
6. 설치·테스트·Windows 예약 실행 스크립트와 초보자용 README를 함께 만든다.

먼저 파일 구조와 구현 계획을 보여주고, 내가 승인하면 코드를 작성해줘.
```

Codex가 계획을 보여주면 파일별 역할을 확인한 뒤 “진행해”라고 답합니다. 이때 `SKILL.md`에는 에이전트의 규칙을, `runtime`에는 실행 코드를, `scripts`에는 설치·로그인·테스트 명령을 넣도록 요청합니다.

> [꿀팁 더하기] 이 결과물의 중심은 MCP 서버가 아니라 **Codex Skill**입니다. Skill은 “무엇을 해야 하는가”를 설명하고, runtime과 scripts가 실제 작업을 수행합니다.

### Step 3. 주간학습안내 입력 방식 구현하기

#### 방법 A. 학교 홈페이지에서 찾기

학교 홈페이지에 주간안내가 매주 올라오는 경우, 게시판 주소와 첨부파일 규칙을 설정합니다. 에이전트는 실행 날짜가 포함된 게시물을 찾고 HWP·HWPX·이미지 파일을 내려받습니다.

#### 방법 B. 로컬 폴더에 파일을 계속 추가하기

학교 홈페이지에 주안이 올라오지 않는 경우를 위해 로컬 방식을 함께 만듭니다. 기본 폴더 예시는 다음과 같습니다.

```text
%LOCALAPPDATA%\LessonAgent\plans
```

매주 파일을 지우지 않고 계속 추가합니다. 파일명에는 날짜를 넣습니다.

```text
2026-08-17_주간학습안내.hwpx
2026-08-24_2026-08-28_주간학습안내.hwp
```

에이전트는 오늘 날짜가 들어간 파일을 고르고, 같은 날짜 파일이 여러 개면 가장 최근 수정 파일을 사용합니다. 날짜가 없는 파일은 자동 선택하지 않으며, 원본 파일은 삭제하지 않습니다.

> [꿀팁 더하기] 파일을 “교체”하는 방식보다 날짜 파일을 “추가”하는 방식이 시험에 유리합니다. 지난 날짜를 다시 실행해 오류를 재현할 수 있기 때문입니다.

### Step 4. 차시명에서 검색어를 만들고 인디스쿨 결과 검증하기

검색어를 차시명 전체로 복사하면 다른 단원 자료가 섞일 수 있습니다. 과목별로 중심 개념과 보조 핵심어를 분리합니다.

| 과목 | 검색 규칙 예시 |
|---|---|
| 국어 | `견학 기록문 읽기 (1/2)` → 차시 수와 활동 동사를 빼고 `견학기록문` |
| 수학·과학 | `소수의 나눗셈`을 중심어로 검색하되 제목에 `자연수`가 있는 글 우선. `기체의 부피` 검색 후 `온도` 포함 여부 확인 |
| 마무리·복습 | 주간안내 단원명 + `복습`, `총정리`, `마무리` 조합을 각각 검색 |
| 사회·도덕 | 개념어와 행동어를 분리. `기후변화` 검색 후 `대응`·`실천`이 있는 글 우선 |
| 음악 | 차시 수만 빼고 활동 제목 전체 검색 |
| 미술 | 연차시 내용이 다르면 검색어를 나누고, 차시 관련 2건 + 최근 인기글 3건 제공 |

결과를 고를 때는 다음 순서를 코드로 고정합니다.

1. 게시글 **제목**에 중심어와 보조어가 모두 있는지 확인합니다.
2. 제목 후보가 있으면 다른 단원의 대형 모음글을 제외합니다.
3. 제목 후보가 없을 때만 본문에서 핵심어를 확인합니다.
4. 0건이면 같은 검색어를 최대 3회 다시 불러옵니다.
5. 실패한 과목에는 실제 검색어와 이유를 남기고, 성공한 과목은 계속 발송합니다.

미술의 최근 인기글은 7일 범위에서 3건이 부족하면 14일, 21일, 28일 순서로 넓힙니다.

> [꿀팁 더하기] ‘검색어’와 ‘선별 조건’을 분리해 저장하세요. 예를 들어 검색어는 `소수의 나눗셈`, 선별 조건은 제목에 `자연수` 포함입니다. 그래야 검색 결과가 많아도 다른 단원 글을 걸러낼 수 있습니다.

### Step 5. 카카오톡과 인디스쿨 로그인 연결하기

#### 5-1. 카카오 연결

Kakao Developers에서 애플리케이션을 만들고 REST API 키를 준비합니다. 카카오 로그인 Redirect URI에는 다음 주소를 등록합니다.

```text
http://localhost:8765/callback
```

메시지 형식은 다음처럼 짧게 고정합니다.

```text
📚 과목: 수학
🔎 검색어: 소수의 나눗셈
📝 제목: 게시글 제목
🔗 링크: 게시글 링크
💡 핵심요약: 핵심 내용 한 문장
⚠ 확인사항: 필요할 때만
```

#### 5-2. 인디스쿨 세션 연결

일반 Chrome의 쿠키를 복사하지 않고, 에이전트 전용 Chrome 프로필을 만듭니다.

```powershell
.\scripts\start-indischool-session.cmd
```

전용 창에서 인디스쿨에 로그인하고 최소화해 둡니다. 프로필은 OneDrive 밖에 저장해야 브라우저 임시 파일 정리 때 삭제 경고가 생기지 않습니다. 세션이 만료된 경우에만 다시 로그인하도록 예외 처리를 넣습니다.

> [꿀팁 더하기] API 키·토큰·쿠키는 소스 코드나 GitHub에 넣지 말고 사용자의 컴퓨터에만 저장하세요.

### Step 6. 테스트하고 자동 실행·배포하기

#### 6-1. DryRun으로 확인하기

카카오톡으로 보내기 전에 다음 명령으로 읽은 시간표와 검색어를 확인합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26 -DryRun
```

날짜 범위, 학급, 누적 차시 순번, 차시명, 실제 검색어, 제목 필터 결과가 맞는지 확인합니다. 다른 단원 글이 섞이면 Step 4의 검색어·선별 규칙을 고친 뒤 다시 실행합니다.

#### 6-2. 실제 발송하기

```powershell
.\scripts\run.ps1 -Date 2026-06-26
```

카카오톡 나와의 채팅에 과목·검색어·제목·링크·한 줄 요약이 도착하면 1차 테스트가 끝납니다.

#### 6-3. 매일 자동 실행 등록하기

Windows 작업 스케줄러에 오전 8시 40분 작업을 등록합니다.

```powershell
.\scripts\install-task.ps1
```

컴퓨터 전원, Windows 로그인, 인터넷, 인디스쿨 세션, 해당 날짜의 주간안내가 모두 필요합니다.

#### 6-4. 패키징하고 공개하기

다음 구조로 저장소를 정리합니다.

```text
skills/      에이전트 규칙(SKILL.md)
runtime/     실행 코드
scripts/     설치·로그인·테스트·예약 실행
README.md    완성품 설치 방법
docs/        초보자용 안내와 제작 원고
```

테스트와 플러그인 검증을 끝낸 뒤 GitHub에 공개합니다. 인디스쿨 운영자의 허가와 이용약관을 먼저 확인하고, 자료 파일 자체가 아니라 허용된 게시글 링크와 짧은 요약만 제공합니다.

## [실전 활용하기]

이 구조는 백석초등학교 6학년 2반에만 한정되지 않습니다. 설치할 때 학교 주소, 학년, 반, 전담 과목을 바꾸면 다른 학교에서도 사용할 수 있습니다. 주간안내가 홈페이지에 올라오지 않는 학교는 날짜 파일을 `plans` 폴더에 계속 추가하면 되고, 시험 기간에는 이전 날짜 파일로 검색 규칙을 다시 검증할 수 있습니다.

주간학습안내 대신 행사 일정표·동아리 계획표·방과후 시간표를 입력하도록 규칙을 바꾸면, 필요한 자료나 안내 링크를 찾아 보내는 다른 교사용 에이전트로 확장할 수도 있습니다.

## 활용만 하고 싶은 사람에게

직접 제작하지 않고 완성된 에이전트를 활용하려면 GitHub 저장소에서 **Code → Download ZIP**을 선택하세요. 설치 방법은 저장소의 `README.md`와 `docs/초보자용-설치안내.md`에 따로 정리되어 있습니다.
