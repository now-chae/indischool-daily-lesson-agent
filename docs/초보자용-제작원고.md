# 주간학습안내 → 인디스쿨 자료 추천 에이전트 만들기

이 원고는 **완성된 프로그램을 설치하는 방법**이 아니라, 교사가 Codex에서 비슷한 에이전트를 직접 만드는 과정을 재현하는 튜토리얼입니다. 코드를 처음 보는 사람도 아래 순서를 그대로 따라갈 수 있게 작성했습니다.

> 완성 프로그램을 바로 활용하고 싶다면 이 과정을 건너뛰고 GitHub 저장소의 `README.md`와 `docs/초보자용-설치안내.md`를 따라 설치하세요.

## 완성 모습

매일 정해진 시각에 에이전트가 다음 일을 합니다.

1. 학교 홈페이지 또는 컴퓨터의 주간학습안내를 읽습니다.
2. 해당 학급의 오늘 시간표와 차시명을 확인합니다.
3. 체육·영어처럼 제외한 과목을 빼고 과목별 검색어를 만듭니다.
4. 인디스쿨에서 제목과 차시의 관련성을 확인해 자료를 고릅니다.
5. 과목·검색어·제목·링크·한 줄 요약을 카카오톡 ‘나와의 채팅’으로 보냅니다.

## 시작 전에 준비할 것

- Windows 컴퓨터와 Chrome
- Codex
- 인디스쿨 계정
- Kakao Developers 계정과 REST API 키
- 주간학습안내가 올라오는 학교 홈페이지 주소 또는 주간안내 파일
- 선택 사항: 이미지 주간안내를 읽기 위한 OpenAI API 키

## 1단계. 에이전트의 규칙을 먼저 글로 쓴다

코드를 만들기 전에 “무엇을 읽고, 언제 멈추고, 무엇을 보내는가”를 문장으로 고정합니다. 다음 내용을 메모장에 먼저 작성하세요.

```text
사용자가 설정한 학교·학년·반의 주간학습안내를 확인한다.
오늘 날짜와 해당 반의 1~6교시를 먼저 확정한다.
날짜·시간표·차시명을 확신하지 못하면 추측하지 말고 확인 필요로 표시한다.
체육·영어 등 사용자가 지정한 전담 과목은 제외한다.
국어·수학은 차시에서 핵심 명사를 뽑고, 사회·과학·도덕은 중심 개념과 행동어를 분리한다.
검색 결과는 제목에 핵심어가 모두 들어간 글을 우선한다.
검색 결과가 없으면 같은 검색어를 최대 3회 다시 확인한다.
카카오 메시지는 과목, 검색어, 제목, 링크, 핵심요약 한 문장만 보낸다.
자료 파일 자체를 복사해 보내지 않고 게시글 링크만 제공한다.
```

이 규칙을 먼저 정하면 나중에 차시명을 잘못 읽거나 다른 단원 자료를 고르는 문제를 줄일 수 있습니다.

## 2단계. Codex에 Skill 제작을 요청한다

Codex에서 새 대화를 열고 아래 요청문을 그대로 붙여넣습니다. 괄호 부분만 자신의 상황에 맞게 바꿉니다.

```text
교사용 주간학습안내 자료 추천 에이전트를 Codex Skill로 만들어줘.

사용자 설정값:
- 학교 홈페이지: (주소 또는 로컬 파일 폴더 사용 여부)
- 학년: (예: 6)
- 반: (예: 2)
- 제외 과목: (예: 체육, 영어)
- 발송 시각: (예: 매일 오전 8시 40분)

반드시 포함할 기능:
1. 학교 홈페이지에서 주간안내 파일을 찾는 방식과, 로컬 폴더에 날짜가 포함된 파일을 계속 추가하는 방식을 모두 지원한다.
2. 주간안내의 날짜·학급·교시·차시명을 두 번 확인하고, 확신이 없으면 추측하지 않는다.
3. 과목별 검색어를 차시명에서 자동으로 만든다. 괄호 속 차시 수는 제거한다.
4. 인디스쿨 게시판에서 제목의 핵심어 일치 여부를 확인하고 인기순으로 고른다.
5. Kakao REST API로 나와의 채팅에 과목·검색어·제목·링크·핵심요약만 보낸다.
6. Windows에서 매일 자동 실행할 수 있는 설치 스크립트와 초보자용 README를 함께 만든다.

먼저 파일 구조와 구현 계획을 보여주고, 승인 후 코드를 작성해줘.
```

Codex가 제시한 계획을 확인한 뒤 “진행해”라고 답합니다. Skill 설명 파일(`SKILL.md`)에는 규칙을, 실행 코드에는 실제 동작을, README에는 사용법을 넣도록 요청하세요.

## 3단계. 주간안내 읽기와 검색 규칙을 구현한다

이 단계에서 에이전트의 핵심 판단을 만듭니다.

### 3-1. 주간안내 입력을 두 가지로 만든다

사용자마다 학교 홈페이지에 주안이 올라오지 않을 수 있으므로 두 방식을 모두 구현합니다.

- **웹 방식**: 학교 홈페이지 게시판에서 실행 날짜가 포함된 주간안내를 찾고 첨부파일을 내려받습니다.
- **로컬 방식**: `%LOCALAPPDATA%\LessonAgent\plans` 같은 폴더에 사용자가 파일을 계속 추가합니다.

로컬 파일은 `2026-08-17_주간학습안내.hwpx`, `2026-08-24_2026-08-28_주간학습안내.hwp`처럼 파일명에 날짜를 넣습니다. 에이전트는 오늘 날짜를 포함하는 파일만 선택하고, 같은 날짜 파일이 여러 개면 가장 최근 수정 파일을 사용합니다. 원본은 삭제하지 않습니다.

### 3-2. 차시명에서 검색어를 만드는 규칙을 만든다

검색어를 과목마다 기계적으로 복사하면 엉뚱한 자료가 섞입니다. 다음처럼 중심 개념과 보조 핵심어를 분리합니다.

- 국어 읽기·쓰기: 활동 동사와 차시 수를 빼고 핵심 명사를 붙입니다. 예: `견학 기록문 읽기 (1/2)` → `견학기록문`
- 국어·수학의 `마무리하기`, `복습`, `스스로 하기`: 주간안내의 단원명과 `복습`, `총정리`, `마무리`를 조합해 여러 검색어를 만듭니다.
- 수학·과학: 중심 개념과 보조 핵심어를 함께 관리합니다. 예: `소수의 나눗셈을 자연수의 나눗셈과 비교해 볼까요` → 검색어 `소수의 나눗셈`, 제목에는 `자연수`도 있어야 합니다.
- 사회·도덕: 개념어와 행동어를 나눕니다. 예: `기후변화에 대응하는 우리의 실천` → `기후변화`로 검색한 뒤 제목이나 본문에 `대응` 또는 `실천`이 있는 글을 우선합니다.
- 음악: 차시 수만 빼고 활동 제목 전체를 검색합니다.
- 미술: 연차시의 내용이 다르면 검색어를 각각 만들고, 차시 관련 자료 2건과 최근 인기글 3건을 분리합니다. 최근 7일에 3건이 부족하면 14일, 21일, 28일 순서로 범위를 넓힙니다.

### 3-3. 검색 결과를 검증한다

검색어가 같아도 다른 단원의 대형 모음글이 먼저 나올 수 있습니다. 따라서 다음 순서로 필터를 구현합니다.

1. 게시글 **제목**에 중심 개념어와 보조 핵심어가 모두 있는지 확인합니다.
2. 제목 후보가 있으면 다른 단원의 전체 모음글은 제외합니다.
3. 제목 후보가 없을 때만 본문에서 핵심어를 확인합니다.
4. 0건이면 같은 검색어를 최대 3회 다시 불러온 후 0건으로 확정합니다.
5. 실패한 과목은 실제 검색어와 이유를 메시지에 남기고, 성공한 과목은 정상 발송합니다.

이 규칙을 테스트 코드로 먼저 고정하면 “소수의 나눗셈” 검색 결과에 “비례식과 비례배분” 글이 섞이는 오류를 막을 수 있습니다.

## 4단계. 카카오톡 발송을 연결한다

### 4-1. Kakao Developers 설정

1. Kakao Developers에서 애플리케이션을 만듭니다.
2. 카카오 로그인 설정에서 Redirect URI를 등록합니다.

```text
http://localhost:8765/callback
```

3. REST API 키를 복사해 에이전트의 로컬 설정에 저장합니다.

### 4-2. 메시지 형식을 고정한다

메시지는 길게 설명하지 않고 다음 형식만 사용합니다.

```text
📚 과목: 수학
🔎 검색어: 소수의 나눗셈
📝 제목: (게시글 제목)
🔗 링크: (게시글 링크)
💡 핵심요약: (핵심 내용 한 문장)
⚠ 확인사항: (필요할 때만)
```

API 키와 토큰은 GitHub에 절대 기록하지 않습니다. 사용자의 컴퓨터에만 저장하도록 설정합니다.

## 5단계. 인디스쿨 로그인 세션을 연결한다

일반 Chrome의 쿠키를 복사하는 대신 에이전트 전용 Chrome 프로필을 만듭니다.

```powershell
.\scripts\start-indischool-session.cmd
```

전용 창에서 인디스쿨에 로그인하고 창을 닫지 않은 채 최소화합니다. 프로필은 OneDrive 밖의 로컬 경로에 저장해야 파일 정리 때 OneDrive 삭제 경고가 나오지 않습니다.

에이전트는 이 세션을 재사용합니다. 인디스쿨에서 세션을 만료했을 때만 다시 로그인하도록 예외 처리를 넣습니다.

## 6단계. 테스트·자동 실행·배포를 완성한다

### 6-1. DryRun 테스트

먼저 카카오톡으로 보내지 않고 시간표와 검색어만 확인합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26 -DryRun
```

여기서 반드시 확인할 것:

- 날짜 범위와 해당 반 시간표가 맞는가?
- 과목별 누적 차시 순번과 학습내용이 맞게 대응하는가?
- 국어·수학·사회·과학의 검색어가 핵심어를 빠뜨리지 않았는가?
- 검색 결과 제목이 실제 차시와 같은 단원인가?

### 6-2. 실제 1회 발송

```powershell
.\scripts\run.ps1 -Date 2026-06-26
```

카카오톡 나와의 채팅에서 과목, 검색어, 제목, 링크, 한 줄 요약만 깔끔하게 도착하는지 확인합니다.

### 6-3. 매일 자동 실행

Windows 작업 스케줄러 등록 기능을 만듭니다. 예시는 오전 8시 40분입니다.

```powershell
.\scripts\install-task.ps1
```

자동 실행 조건은 컴퓨터 전원, Windows 로그인, 인터넷, 인디스쿨 세션, 해당 날짜의 주간안내 파일입니다.

### 6-4. 패키징

다음 파일을 하나의 공개 저장소에 넣습니다.

- `skills/.../SKILL.md`: 에이전트 규칙
- `runtime/`: 실제 실행 코드
- `scripts/`: 설치·로그인·테스트·예약 스크립트
- `README.md`: 이미 만들어진 에이전트의 설치 설명
- `docs/초보자용-설치안내.md`: 설치만 하려는 사람용 안내

테스트, 플러그인 검증, 비밀키 검색을 끝낸 뒤 GitHub에 공개합니다. 인디스쿨 이용약관과 운영자의 허가 범위를 먼저 확인하고, 자료 파일 자체가 아니라 허용된 링크와 짧은 요약만 제공합니다.

## 활용만 하고 싶은 사람에게 안내할 문장

직접 제작하지 않고 완성된 에이전트를 활용하려는 사람은 GitHub 저장소에서 **Code → Download ZIP**을 선택한 뒤, 저장소의 `README.md`와 `docs/초보자용-설치안내.md`를 순서대로 따라 하면 됩니다. 설치 과정에서는 자신의 학교 주소(또는 로컬 주간안내 폴더), 학년, 반, 제외 과목, Kakao REST API 키만 입력하면 됩니다.
