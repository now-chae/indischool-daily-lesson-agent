# 📘 주간학습안내를 읽고 인디스쿨 자료를 보내는 에이전트 만들기

## [이번 챕터에서는]

매일 아침 주간학습안내를 확인하고, 오늘 수업에 필요한 인디스쿨 자료를 찾아 카카오톡 ‘나와의 채팅’으로 보내는 에이전트를 만들어 봅니다. 이 원고는 완성 프로그램의 설치 설명서가 아니라, 교사가 같은 에이전트를 직접 제작하는 과정을 6단계로 안내합니다.

학교 홈페이지에 주간안내가 올라오는 경우와, 홈페이지에 올라오지 않아 컴퓨터 폴더에 파일을 계속 추가하는 경우를 모두 다룹니다. 마지막에는 직접 만들지 않고 완성품만 활용하려는 사람을 위해 GitHub 다운로드 방법도 짧게 안내합니다.

## [한눈에 보기]

이 에이전트는 Codex Skill, Python runtime, PowerShell 실행 스크립트, 전용 Chrome 로그인 세션, Kakao REST API, 인디스쿨 게시판 탐색 코드로 구성됩니다. 이미지 주간안내를 자동으로 읽을 때만 OpenAI API 키를 선택적으로 사용하며, HWP·HWPX 파일은 별도 키 없이 읽도록 구성합니다.

완성된 흐름은 다음과 같습니다.

```text
규칙 설계
   ↓
Codex에 Skill과 파일 구조 요청
   ↓
주간안내 판독 + 과목별 검색어 생성
   ↓
저장된 Chrome 세션으로 인디스쿨 접속
   ↓
게시판·학년 탭·인기순 검색·제목 검증
   ↓
카카오톡 테스트 → 매일 자동 실행 → 패키징
```

## [실습하기]

### Step 1. 에이전트가 지킬 규칙 작성하기

Codex에 바로 “만들어 줘”라고 하기 전에, 에이전트가 무엇을 읽고 언제 멈출지 먼저 적습니다. 다음 문장을 메모장에 복사해 자신의 학교 상황에 맞게 고쳐 보세요.

```text
사용자가 설정한 학교·학년·반의 주간학습안내를 확인한다.
오늘 날짜와 해당 반의 1~6교시를 먼저 확정한다.
날짜·시간표·차시명을 확신하지 못하면 추측하지 말고 확인 필요로 표시한다.
체육·영어 등 사용자가 지정한 전담 과목은 제외한다.
차시명에서 과목별 핵심 검색어와 보조 핵심어를 만든다.
인디스쿨 게시글은 제목에 핵심어가 모두 있는 자료를 우선한다.
자료 파일 자체를 복사하지 않고 허용된 게시글 링크와 한 줄 요약만 보낸다.
카카오 메시지는 과목·검색어·제목·링크·핵심요약만 표시한다.
```

이 규칙은 에이전트의 설계도입니다. 나중에 엉뚱한 단원의 자료가 섞이면 검색어 규칙과 제목 필터를 이 부분부터 고칩니다.

> [꿀팁 더하기] ‘정확하지 않으면 보내지 않는다’는 규칙을 처음부터 넣으세요. 차시명 한 글자를 추측해서 검색하는 것보다 확인 필요를 표시하는 것이 안전합니다.

### Step 2. Codex에 전체 파일 구조와 Skill의 뼈대를 요청하기

Codex에서 새 대화를 열고 아래 프롬프트를 그대로 붙여넣습니다. 대괄호 안의 학교·학년·반·전담 과목·발송 시각만 자신의 상황으로 바꿉니다.

```text
교사용 ‘주간학습안내 → 인디스쿨 자료 추천 → 카카오톡 발송’ 에이전트를 만들어줘.

사용자 설정값은 다음과 같다.
- 학교 홈페이지: [학교 홈페이지 주소 또는 없음]
- 학년과 반: [예: 6학년 2반]
- 제외 과목: [예: 체육, 영어]
- 발송 시각: [예: 매일 오전 8시 40분]
- 시간대: Asia/Seoul

먼저 아래 파일 구조를 그대로 만들고, 각 파일의 역할을 설명해줘.

파일별 요구사항:
1. SKILL.md에는 주간안내 판독, 차시명 검증, 과목별 검색어, 인디스쿨 제목 필터, 카카오 메시지 형식을 사람이 읽을 수 있는 규칙으로 작성한다.
2. config.py에는 학교 주소, 학년, 반, 제외 과목, 발송 시각, 로컬 주간안내 폴더, 전용 Chrome 프로필 경로를 설정값으로 둔다.
3. weekly_plan.py에는 HWP/HWPX/이미지 판독, 날짜·학급·요일·교시 확인, 과목별 누적 차시 대응을 구현한다.
4. school.py에는 홈페이지 방식과 날짜 파일 누적 방식의 주간안내 입력을 구현한다.
5. indischool.py에는 저장된 로그인 세션으로 게시판에 접속하고 학년 탭, 인기순 검색, 제목·본문 검증을 구현한다.
6. kakao.py와 message.py에는 나와의 채팅 발송과 짧은 메시지 형식을 구현한다.
7. app.py와 cli.py에는 한 번 실행, 미리보기, 카카오 테스트, 자동 실행 진입점을 구현한다.
8. scripts 폴더에는 설치, 로그인 세션 시작, 테스트, 작업 스케줄 등록·해제 스크립트를 만든다.
9. 모든 학교 이름과 6학년 2반을 코드에 하드코딩하지 말고 설치 질문으로 입력받게 한다.
10. 먼저 계획과 파일 구조만 보여주고, 내가 ‘진행해’라고 답한 뒤 코드를 작성한다.
```

Codex가 계획을 보여주면 파일별 역할과 설정값이 맞는지 확인한 뒤 “진행해”라고 답합니다.

### Step 3. 주간학습안내 입력 방식을 구현하기

학교마다 주안 게시 방식이 다르므로 웹 방식과 로컬 파일 방식을 모두 구현합니다. 다음 프롬프트를 이어서 Codex에 입력합니다.

```text
주간학습안내 입력 방식을 두 가지로 구현해줘.

첫째, web 방식은 설정한 학교 홈페이지에서 실행 날짜가 포함된 주간안내 게시물을 찾고 HWP·HWPX·JPG·PNG·WEBP 첨부파일을 내려받는다.

둘째, local 방식은 기본 폴더 %LOCALAPPDATA%\LessonAgent\plans에 사용자가 주간안내 파일을 계속 추가하게 한다. 파일명에 YYYY-MM-DD 날짜가 하나 있으면 그 날짜의 자료로, YYYY-MM-DD_YYYY-MM-DD 날짜가 두 개 있으면 그 기간의 자료로 인식한다.

예시 파일명은 다음과 같다.
2026-08-17_주간학습안내.hwpx
2026-08-24_2026-08-28_주간학습안내.hwp

오늘 날짜를 포함하는 후보만 고르고, 같은 날짜 후보가 여러 개면 가장 최근 수정 파일을 선택한다. 날짜가 없는 파일은 선택하지 않는다. 원본 파일은 삭제하거나 이동하지 않는다.

설정값에는 LESSON_AGENT_PLAN_SOURCE=web|local과 LESSON_AGENT_LOCAL_PLAN_DIR를 추가한다. 자료가 없으면 원본을 찾은 위치와 확인 이유를 메시지에 남긴다.
```

로컬 방식에서는 파일을 교체하지 않고 계속 추가합니다. 지난 날짜의 파일이 남아 있어야 테스트 중 오류를 다시 재현할 수 있습니다.

### Step 4. 차시명에서 검색어를 만들고 인디스쿨을 탐색하기

차시명 전체를 검색창에 그대로 넣으면 다른 단원 자료가 섞일 수 있습니다. 다음 프롬프트로 과목별 검색어와 제목 필터를 구현합니다.

```text
차시명 분석과 인디스쿨 검색 규칙을 구현해줘.

1. 국어 읽기·쓰기 차시는 활동 동사와 괄호 속 차시 수를 빼고 핵심 명사를 붙인다. ‘견학 기록문 읽기 (1/2)’는 ‘견학기록문’으로 검색한다.
2. 국어·수학의 ‘마무리하기·복습·총정리·스스로 하기’는 주간안내에서 단원명을 찾아 ‘단원명 복습’, ‘단원명 총정리’, ‘단원명 마무리’를 각각 검색한다.
3. 수학·과학은 중심 검색어와 보조 핵심어를 분리한다. ‘소수의 나눗셈을 자연수의 나눗셈과 비교해 볼까요’는 ‘소수의 나눗셈’으로 검색하되 제목에 ‘자연수’가 있는 글을 우선한다. ‘기체의 부피는 온도에 따라 어떻게 될까?’는 ‘기체의 부피’로 검색하되 ‘온도’가 있는 글을 우선한다.
4. 사회·도덕은 개념어와 행동어를 분리한다. ‘기후변화에 대응하는 우리의 실천’은 ‘기후변화’로 검색한 뒤 제목이나 본문에 ‘대응’ 또는 ‘실천’이 있는 글을 우선한다. ‘인공지능 로봇 사용’은 ‘인공지능’으로 검색한 뒤 ‘사용’ 또는 ‘활용’이 있는 글을 우선한다.
5. 음악은 차시 수만 빼고 활동 제목 전체를 검색한다.
6. 미술 연차시의 내용이 다르면 검색어를 나누고 차시 관련 자료 2건과 최근 인기글 3건을 제공한다. 최근 인기글은 7일, 14일, 21일, 28일 순으로 범위를 넓힌다.
7. 검색 결과는 제목에 중심어와 보조어가 모두 있는 글을 최우선으로 한다. 제목 후보가 있으면 다른 단원의 대형 모음글을 제외하고, 제목 후보가 없을 때만 본문을 확인한다.
8. 검색 결과가 0건이면 같은 검색어를 최대 3회 다시 불러온 뒤에만 0건으로 확정한다.
9. 실제 검색어, 제목 필터 조건, 재조회 횟수를 실행 기록에 남긴다.
```

이제 인디스쿨 게시판 탐색을 구현합니다. 아래 프롬프트를 그대로 입력합니다.

```text
인디스쿨 게시판 탐색을 Playwright로 구현해줘.

게시판 탐색 순서는 다음과 같다.
1. 저장된 로그인 세션으로 https://indischool.com/boards/libLanguage에 접속한다.
2. 로그인 페이지로 이동했거나 로그인 버튼만 보이면 login_required 오류를 낸다.
3. 과목 이름과 정확히 일치하는 게시판 링크를 찾고 해당 게시판으로 이동한다.
4. 국어·수학·사회·과학 등 학년 탭이 있는 게시판에서는 설정한 학년의 탭을 클릭한다. 미술·음악처럼 학년 탭이 없으면 게시판 기본 주소를 사용한다.
5. 검색 URL에 order_by=likes, search_target=text, local_query=검색어를 넣어 인기순으로 검색한다.
6. 제목 핵심어 필터가 필요한 검색은 1~5페이지까지 확인하고, 게시글 제목에 필요한 핵심어가 모두 있는 글을 우선한다.
7. 게시글 링크는 https://indischool.com/boards/... 형식의 정규 URL만 남기고 첨부파일 다운로드 주소는 제외한다.
8. 선택한 게시글에 들어가 본문 영역에서 요약에 필요한 텍스트를 읽는다.
9. 검색 결과가 비어 있으면 같은 페이지를 최대 3회 다시 불러온다.
10. 작업이 끝나면 새 검색 탭만 닫고 저장된 로그인 세션과 전용 Chrome 창은 유지한다.
```

### Step 5. 로그인 세션을 저장하고 카카오톡을 연결하기

전용 Chrome을 단순히 “로그인하세요”라고 요청하면 다음 실행 때 다시 로그인해야 할 수 있습니다. 반드시 **프로필을 저장하고 재사용하는 방식**을 요구해야 합니다. 다음 프롬프트를 입력합니다.

```text
인디스쿨 로그인 세션을 매번 새로 만들지 않고 저장·재사용하도록 구현해줘.

1. 프로필 경로는 %LOCALAPPDATA%\LessonAgent\indischool-profile로 만들고 OneDrive 안의 경로는 거부한다.
2. scripts/start-indischool-session.cmd를 만들어 Chrome을 다음 옵션으로 실행한다.
   --remote-debugging-address=127.0.0.1
   --remote-debugging-port=9222
   --user-data-dir="%LOCALAPPDATA%\LessonAgent\indischool-profile"
   https://indischool.com/
3. 최초 1회만 전용 Chrome 창에서 사용자가 직접 인디스쿨에 로그인하도록 한다.
4. 로그인 후 쿠키와 local storage가 프로필 폴더에 저장되도록 하고, 창을 닫지 않고 최소화해도 되게 한다.
5. 실제 검색 실행에서는 새 브라우저를 launch하지 말고 Playwright connect_over_cdp("http://127.0.0.1:9222")로 이미 열린 전용 Chrome에 연결한다.
6. 연결된 브라우저 context의 쿠키를 사용해 게시판을 탐색한다.
7. /login으로 리디렉션되거나 로그인 버튼만 보이면 session_expired 오류를 남기고 자료 검색을 중단한다.
8. 세션이 정상인 경우에는 사용자가 다시 로그인하지 않도록 한다.
9. setup-indischool 명령을 별도로 제공해 세션이 만료됐을 때만 로그인 창을 다시 열 수 있게 한다.
10. 프로필 폴더가 OneDrive 경로인지 시작 전에 검사하고, OneDrive이면 실행하지 않는다.
```

카카오톡 연결도 구체적으로 요청합니다.

```text
Kakao Developers REST API를 연결해줘.

1. 설정값에서 Kakao REST API 키와 refresh token을 읽고 소스 코드에 하드코딩하지 않는다.
2. Redirect URI는 http://localhost:8765/callback으로 고정한다.
```

### Step 6. 테스트하고 자동 실행·배포하기

먼저 카카오톡으로 보내지 않는 DryRun을 만듭니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26 -DryRun
```

DryRun 화면에서 날짜 범위, 학급, 누적 차시 순번, 차시명, 실제 검색어, 제목 필터 결과, 인디스쿨 재조회 횟수를 확인합니다. 다른 단원 글이 섞이면 Step 4 프롬프트의 검색어와 제목 조건을 고친 뒤 다시 실행합니다.

문제가 없으면 실제 발송을 시험합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26
```

매일 오전 8시 40분에 실행하려면 Windows 작업 스케줄러 등록 스크립트를 만듭니다.

```powershell
.\scripts\install-task.ps1
```

자동 실행 조건은 컴퓨터 전원, Windows 로그인, 인터넷 연결, 전용 Chrome 세션, 해당 날짜의 주간안내 파일입니다. 예약을 해제하는 명령도 함께 만듭니다.

```powershell
.\scripts\remove-task.ps1
```

최종 패키지는 다음 구조로 정리합니다.

```text
indischool-daily-lesson-agent/
├── .codex-plugin/plugin.json          # Codex 플러그인 이름과 설명
├── README.md                          # 완성품 설치 방법
├── docs/초보자용-설치안내.md            # 설치만 하는 사람용 안내

├── skills/.../SKILL.md                # 에이전트가 지킬 규칙
├── runtime/pyproject.toml             # Python 패키지와 의존성
```

각 파일을 만든 뒤 “모든 학교·학년·반을 설정값으로 지원하는지, 비밀키가 GitHub에 포함되지 않았는지, 프로필이 OneDrive 밖인지, 테스트 명령이 실제로 동작하는지 확인해줘”라고 Codex에 검토를 요청합니다.

## [실전 활용하기]

이 구조는 특정 학교에만 한정되지 않습니다. 설치할 때 학교 주소, 학년, 반, 전담 과목을 바꾸면 다른 학교에서도 사용할 수 있습니다. 주간안내가 홈페이지에 올라오지 않는 학교는 날짜 파일을 `plans` 폴더에 계속 추가하면 되고, 시험 기간에는 이전 날짜 파일로 검색 규칙을 다시 검증할 수 있습니다.

인디스쿨 운영자의 허가와 이용약관을 먼저 확인하고, 자료 파일 자체가 아니라 허용된 게시글 링크와 짧은 요약만 제공합니다. API 키·토큰·쿠키는 소스 코드와 GitHub에 기록하지 않습니다.

## 활용만 하고 싶은 사람에게

직접 제작하지 않고 완성된 에이전트를 활용하려면 GitHub 저장소에서 **Code → Download ZIP**을 선택하세요. 설치 방법은 저장소의 `README.md`와 `docs/초보자용-설치안내.md`에 따로 정리되어 있습니다.
