# 📘 주간학습안내를 읽고 오늘의 수업자료를 보내는 에이전트 만들기

## 이 원고를 읽기 전에

이 원고는 GitHub에서 완성된 프로그램을 내려받아 설치하는 설명서가 아닙니다. Codex에게 요구사항을 설명하고, 설계안을 확인하고, 파일을 하나씩 만들고, 과거 주안으로 시험하면서 **같은 종류의 에이전트를 처음부터 제작하는 방법**을 안내합니다.

완성품을 바로 사용하고 싶은 분은 이 원고의 마지막에 있는 QR 코드나 GitHub 링크로 이동해 저장소의 `README.md`와 `docs/초보자용-설치안내.md`를 따라가면 됩니다. 두 문서는 사용자가 다르므로, 이 원고에는 완성품 설치 절차를 반복해서 싣지 않습니다.

## [이번 챕터에서는]

교사는 매일 주간학습안내를 열어 오늘 시간표를 확인하고, 인디스쿨에서 수업자료를 다시 찾습니다. 여기서는 이 과정을 다음 순서로 자동화합니다.

1. 규칙 설계
2. 파일 및 Skill 구조 설계
3. 주간학습안내 처리 방법 설정
4. 인디스쿨 로그인 세션 설정
5. 카카오톡 연결
6. 테스트 발송 및 규칙 수정
7. 자동화 등록(예약)

완성된 에이전트는 주안의 날짜와 반을 확인하고, 오늘 수업의 차시를 정확히 대응시킨 뒤, 체육·영어를 제외한 과목의 자료를 인디스쿨에서 찾아 카카오톡 ‘나와의 채팅’으로 보냅니다.

## [한눈에 보기]

### 준비물

- Codex가 설치된 Windows 컴퓨터
- 학교 주간학습안내 파일을 넣을 로컬 폴더
- 인디스쿨 교사 계정
- 카카오 계정과 Kakao Developers 앱
- 이미 수업이 끝난 과거 주안 한 개

### Skill, MCP, runtime은 어떻게 다른가요?

Skill은 에이전트가 지킬 작업 규칙을 적는 파일입니다. 예를 들어 “차시명을 확신하지 못하면 확인 필요라고 표시한다”가 Skill의 규칙입니다.

Runtime은 파일을 읽고 브라우저를 조작하는 실제 프로그램입니다. Script는 설치, 로그인, 시험, 예약 실행을 쉽게 호출하는 버튼입니다.

이 프로젝트는 한 사람의 컴퓨터에서 실행하는 **Skill + 로컬 runtime + 스크립트** 구조입니다. 여러 사용자가 서버에 접속하는 MCP 서버를 만드는 작업과는 다릅니다. 나중에 GitHub에 배포할 때는 이 구조를 Codex Skill 패키지로 묶을 수 있습니다.

## [실습하기]

### Step 1. 규칙 설계하기

#### 무엇을 하나요?

코드를 쓰기 전에 에이전트의 판단 기준을 문장으로 정합니다. 이 문장이 나중에 `SKILL.md`의 핵심이 됩니다.

#### 왜 필요한가요?

“자료를 찾아 줘”만으로는 인기만 많은 다른 단원 자료가 섞일 수 있습니다. 어떤 파일을 읽고, 어느 과목을 제외하고, 언제 멈출지를 먼저 정해야 결과를 검증할 수 있습니다.

#### Codex에 이렇게 요청하세요

```text
교사용 ‘주간학습안내 → 인디스쿨 수업자료 → 카카오톡’ 에이전트를 만들고 싶어.

먼저 코드를 만들지 말고, 다음 설정을 바꿔 끼울 수 있는 일반 규칙을 설계해줘.
- 로컬 주안 폴더
- 학년과 반
- 검색하지 않을 전담 과목
- 매일 발송할 시각과 시간대

반드시 포함할 규칙:
1. 오늘 날짜가 주안의 날짜 범위에 들어가는지 먼저 확인한다.
2. 우리 반의 오늘 1~6교시를 읽고, 월요일부터 오늘까지 과목별 등장 횟수와 학습내용 표의 같은 순번을 연결한다.
3. 원본을 확대해 날짜·반·차시명을 두 번 대조하고, 한 글자라도 확신하지 못하면 해당 과목만 ‘확인 필요’로 표시한다.
4. 체육과 영어는 검색하지 않는다.
5. 인디스쿨 게시글 제목을 우선 확인하고, 다른 단원의 모음글은 제외한다.
6. 자료 파일은 복사하지 않고 허용된 게시글 링크와 한 줄 요약만 보낸다.
7. 실제 검색어와 실패 이유를 실행 기록에 남긴다.

정상 처리, 과목만 확인 필요로 처리하는 경우, 전체를 멈추는 경우를 나누어 보여줘.
내가 확인하기 전에는 코드를 작성하지 마.
```

Codex가 학교명이나 학년·반을 코드에 고정하지 않았는지 확인합니다. 설정값만 바꾸면 다른 학교에서도 쓸 수 있어야 합니다.

> 💡 잘못된 자료 한 개보다 ‘확인 필요’ 한 번이 안전합니다. 판독 불확실 시 멈추는 규칙을 처음부터 넣으세요.

### Step 2. 파일 및 Skill 구조 설계하기

#### 무엇을 하나요?

규칙, 주안 판독, 인디스쿨 탐색, 카카오 전송, 설치·예약 기능을 서로 다른 파일로 나눌 설계도를 만듭니다.

#### 왜 필요한가요?

한 파일에 모두 넣으면 검색 규칙을 고칠 때 로그인 코드까지 건드리게 됩니다. 역할을 나누면 오류가 어느 부분에서 생겼는지 찾기 쉽고, 다른 학교용 설정도 재사용할 수 있습니다. 비밀값 관리도 이 단계에서 정해야 나중에 GitHub에 실수로 키를 올리지 않습니다.

#### Codex에 이렇게 요청하세요

```text
앞에서 확정한 규칙을 바탕으로 아래 프로젝트 구조의 설계도를 만들어줘.
아직 코드는 쓰지 말고 각 파일의 역할과 연결 관계만 설명해줘.

indischool-daily-lesson-agent/
├── .codex-plugin/plugin.json
├── .env.example
├── .gitignore
├── README.md
├── docs/초보자용-설치안내.md
├── skills/indischool-daily-lesson-agent/SKILL.md
├── runtime/pyproject.toml
├── runtime/src/lesson_agent/config.py
├── runtime/src/lesson_agent/weekly_plan.py
├── runtime/src/lesson_agent/indischool.py
├── runtime/src/lesson_agent/kakao.py
├── runtime/src/lesson_agent/message.py
├── runtime/src/lesson_agent/cli.py
├── scripts/setup.ps1
├── scripts/start-indischool-session.cmd
└── scripts/run.ps1

설정은 처음부터 다음 원칙으로 설계해줘.
- .env.example에는 변수 이름과 빈 예시만 둔다.
- .gitignore에는 .env와 브라우저 프로필을 넣는다.
- setup.ps1이 로컬 주안 폴더, 학년, 반, 제외 과목, 발송 시각, API 키를 질문한다.
- 실제 .env는 프로젝트 폴더나 OneDrive가 아니라 %LOCALAPPDATA%\\LessonAgent\\config\\.env에 저장한다.
- config.py는 그 로컬 파일만 읽고 코드 안에 키를 적지 않는다.
- Kakao 토큰과 인디스쿨 쿠키는 Windows 로컬 저장소와 OneDrive 밖의 프로필에 둔다.

설계가 맞는지 내가 확인한 뒤에만 파일을 만들도록 해줘.
```

기억할 역할은 다음과 같습니다.

- `SKILL.md`: 에이전트의 판단 규칙
- `config.py`: 학교별로 바뀌는 설정 읽기
- `weekly_plan.py`: HWP·HWPX·이미지에서 주안 읽기
- `indischool.py`: 게시판 검색·제목 필터·요약
- `kakao.py`: 카카오 인증과 전송
- `message.py`: 짧고 일정한 메시지 형식
- `scripts`: 설치·로그인·시험 실행
- `.env.example`: 필요한 변수의 안전한 예시
- `.gitignore`: 비밀값과 세션이 저장소에 올라가지 않게 하는 장치

### Step 3. 주간학습안내 처리 방법 설정하기

#### 무엇을 하나요?

사용자가 컴퓨터 폴더에 주안을 계속 추가하는 방식을 정하고, 표의 시간표와 학습내용을 대응시키는 방법을 구현합니다.

#### 왜 필요한가요?

학교 홈페이지 구조는 학교마다 달라 자동 수집을 공개 패키지의 기본으로 삼기 어렵습니다. 날짜가 포함된 주안 파일을 로컬 폴더에 계속 넣는 방식은 홈페이지 구조와 관계없이 동작하고, 지난 자료를 다시 시험하기도 쉽습니다. 홈페이지 수집이 필요한 제작자는 공개 코드와 분리한 로컬 확장판으로 추가합니다.

#### Codex에 입력 방식부터 요청하세요

```text
주간학습안내를 local 방식으로 구현해줘.

- %LOCALAPPDATA%\\LessonAgent\\plans 폴더에 파일을 계속 추가한다.
- 2026-08-17_주간학습안내.hwpx 또는 2026-08-24_2026-08-28_주간학습안내.hwp처럼 파일명 날짜로 적용 기간을 판단한다.
- 오늘 날짜를 포함하는 파일만 고르고 원본은 삭제하거나 이동하지 않는다.
- 날짜가 없는 current.hwpx 같은 파일은 사용하지 않는다.
- 공개 패키지에는 학교 홈페이지 수집 코드를 넣지 않는다. 홈페이지 수집은 별도의 로컬 확장판으로 보관한다.
```

#### Codex에 표 대응 규칙을 요청하세요

```text
주간학습안내를 다음 순서로 읽어줘.
1. 날짜 범위가 오늘을 포함하는지 확인한다.
2. 우리 반의 오늘 요일 1~6교시 과목을 확정한다.
3. 월요일부터 오늘 교시까지 과목별 누적 등장 횟수를 센다.
4. 학습내용 표에서 그 과목의 같은 순번 행을 고른다.
5. 원본 확대본에서 날짜·반·교시·차시명을 두 번 대조한다.
6. 한 글자라도 불확실하면 그 과목은 검색하지 않고 실제 이유를 기록한다.
```

차시명을 검색어로 바꾸는 규칙도 일반화합니다.

```text
차시명에서 중심 검색어와 보조 필수어를 자동으로 뽑아줘.

- 국어 읽기·쓰기: 활동 동사와 (1/2) 같은 차시 수를 빼고 핵심 명사를 붙인다.
  ‘견학 기록문 읽기 (1/2)’ → ‘견학기록문’
- ‘마무리하기·복습·총정리·스스로 하기’처럼 내용이 없는 차시는 주안의 단원명과 ‘복습·총정리·마무리’를 조합해 여러 검색어를 만든다.
- 수학·과학: 중심 개념과 보조 핵심어를 나눈다. 제목에 두 요소가 모두 있는 자료를 최우선으로 하고, 중심 개념만 있는 대형 모음글은 제외한다.
  ‘소수의 나눗셈을 자연수의 나눗셈과 비교해 볼까요’ → 검색어 ‘소수의 나눗셈’, 필수어 ‘자연수’
  ‘온도가 변하면 기체의 부피는 어떻게 될까?’ → 검색어 ‘기체의 부피’, 필수어 ‘온도’
- 사회·도덕: 개념어와 행동어를 나누고 제목 또는 본문에 행동어가 있는 자료를 우선한다.
- 음악: 차시 수를 빼고 노래·활동 제목 전체를 검색한다.
- 미술: 연차시의 내용이 다르면 검색어를 나누고, 관련 자료 2건과 최근 인기글 3건을 제공한다.

검색어·보조 필수어·제목 필터 결과를 실행 기록에 남겨줘.
```

### Step 4. 인디스쿨 로그인 세션 설정하기

#### 무엇을 하나요?

전용 Chrome에 한 번 로그인하고, 이후 실행은 같은 브라우저 세션에 연결하도록 만듭니다.

#### 왜 필요한가요?

예약 실행 시 사람이 로그인 창을 보고 있을 수 없습니다. 쿠키가 저장된 전용 프로필을 재사용하면 매일 아이디와 비밀번호를 입력하지 않아도 됩니다. 프로필을 OneDrive 안에 두면 Chrome 임시 파일 때문에 수천 개 삭제·동기화 경고가 생길 수 있으므로 로컬 AppData 경로를 사용합니다.

#### Codex에 이렇게 요청하세요

```text
인디스쿨 전용 Chrome 로그인 세션을 만들고 재사용하게 해줘.

- 프로필은 %LOCALAPPDATA%\\LessonAgent\\indischool-profile에 저장하고 OneDrive 경로는 거부한다.
- start-indischool-session.cmd가 --remote-debugging-address=127.0.0.1,
  --remote-debugging-port=9222,
  --user-data-dir="%LOCALAPPDATA%\\LessonAgent\\indischool-profile" 옵션으로 Chrome을 연다.
- 첫 실행 때만 사용자가 직접 로그인한다.
- 검색 실행은 새 Chrome을 만들지 말고 Playwright connect_over_cdp("http://127.0.0.1:9222")로 연결한다.
- /login 화면이면 session_expired를 기록하고 재로그인을 안내한다.
- 정상 세션이면 다시 로그인하라고 묻지 않는다.
```

전용 Chrome이 열리면 직접 로그인하고 창을 닫지 않은 채 최소화합니다. 세션 오류가 나면 같은 프로필과 포트로 열렸는지 먼저 확인합니다.

### Step 5. 카카오톡 연결하기

#### 무엇을 하나요?

에이전트가 찾은 링크와 요약을 카카오톡 ‘나와의 채팅’으로 보내는 통로를 연결합니다.

#### 왜 필요한가요?

인디스쿨 로그인과 카카오 인증은 서로 다른 서비스입니다. 카카오의 리디렉션 주소, 토큰 보관 방법, 메시지 형식을 별도로 설계해야 합니다.

#### Codex에 이렇게 요청하세요

```text
Kakao Developers REST API로 ‘나와의 채팅’ 전송을 구현해줘.

- REST API 키와 Redirect URI는 %LOCALAPPDATA%\\LessonAgent\\config\\.env에서 읽는다.
- Redirect URI 기본값은 http://localhost:8765/callback으로 둔다.
- setup-kakao 흐름으로 최초 인증하고, access/refresh token은 .env가 아니라 Windows 자격 증명 저장소(keyring)에 저장한다.
- TestKakao 흐름으로 자료 검색 없이 시험 메시지를 보낸다.
- 메시지 항목은 📚 과목, 🔎 검색어, 📝 제목, 🔗 링크, 💡 핵심요약, 필요할 때만 ⚠ 확인사항으로 제한한다.
- API 키·토큰·쿠키는 로그, 화면, GitHub에 출력하지 않는다.
```

Kakao Developers의 카카오 로그인 Redirect URI에는 모든 사용자가 로컬에서 실행할 수 있도록 `http://localhost:8765/callback`을 등록합니다. 사용자의 카카오 계정과 REST API 키는 각자의 값입니다.

### Step 6. 테스트 발송 및 규칙 수정하기

#### 무엇을 하나요?

이미 수업이 끝난 과거 주안으로 판독, 검색, 제목 필터, 메시지 형식을 검증합니다. 먼저 화면에만 결과를 표시하고, 그다음 카카오 시험 발송을 합니다.

#### 왜 필요한가요?

과거 주안은 정답 시간표를 알고 있어 오류를 바로 찾을 수 있습니다. 실제 오늘 자료로 처음 시험하면 잘못된 차시를 발견하기 어렵습니다.

#### Codex에 이렇게 요청하세요

```text
2026년 6월 26일 과거 주간학습안내로 DryRun 시험을 해줘.
카카오톡으로 보내지 말고 다음을 보여줘.
- 날짜 범위와 반
- 오늘 1~6교시
- 과목별 누적 순번과 확정 차시명
- 실제 검색어와 보조 필수어
- 제목 우선 필터 결과와 제외 이유
- 검색 실패 과목의 실제 검색어와 이유
```

결과를 확인한 뒤 다음처럼 실제 시험 발송을 요청합니다.

```text
방금 확인한 2026년 6월 26일 결과를 카카오톡 ‘나와의 채팅’으로 시험 발송해줘.
과목, 검색어, 제목, 링크, 핵심요약 한 문장만 보내고,
불확실한 과목은 바로 아래에 ⚠ 확인사항과 실제 검색어를 표시해줘.
```

오류가 나면 날짜별 예외를 추가하지 말고 원인 유형을 찾아 일반 규칙을 수정합니다.

```text
방금 결과를 판독 오류, 누적 순번 오류, 검색어 생성 오류,
제목 필터 오류, 본문 확인 오류, 로그인 세션 오류 중 하나로 분류해줘.
이번 날짜에만 적용되는 예외는 만들지 말고 다른 날짜와 학교에도 적용되는 규칙으로 고쳐줘.
수정 전후의 차시명·검색어·필수어·제목 필터를 보여주고 같은 과거 주안으로 다시 DryRun해줘.
```

### Step 7. 자동화 등록하기(예약)

#### 무엇을 하나요?

검증이 끝난 실행 흐름을 Codex 앱의 예약 메뉴에 등록해 매일 같은 시각에 실행합니다.

#### 왜 필요한가요?

예약을 마지막에 등록해야 잘못 읽은 규칙이 매일 반복되는 일을 막을 수 있습니다. 또한 예약 실행 환경에서 주안 입력 방식과 인디스쿨 로그인 세션에 접근할 수 있는지 확인해야 합니다.

#### Codex에 이렇게 요청하세요

```text
Codex 앱의 예약 메뉴에 이 에이전트를 등록해줘.

- 매일 오전 8시 40분, Asia/Seoul 기준으로 실행한다.
- 오늘 날짜의 주간학습안내를 확인하고 인디스쿨 자료를 검색한다.
- 카카오톡 ‘나와의 채팅’으로 과목·검색어·제목·링크·핵심요약을 보낸다.
- 실행 전에 오늘 날짜의 로컬 주안 파일과 인디스쿨 로그인 세션을 확인한다.
- 판독이나 검색이 실패하면 추측하지 말고 확인 필요와 이유를 보낸다.
- 등록한 예약 이름, 실행 시각, 실행 지시문을 보여준다.
```

예약을 해제할 때는 다음처럼 요청합니다.

```text
Codex 앱의 이 에이전트 예약 실행만 해제해줘.
파일, API 키, 카카오 토큰, 인디스쿨 로그인 세션은 삭제하지 마.
```

예약 실행 전에 로컬 주안 파일, 인터넷, 전용 Chrome 세션을 확인합니다.

## [실전 활용하기]

이제 로컬 주안 폴더, 학년, 반, 제외 과목을 설정값으로 바꾸면 다른 학교에서도 같은 설계를 사용할 수 있습니다. 날짜가 들어간 파일을 `plans` 폴더에 계속 추가하면 됩니다. 홈페이지 수집 기능은 공개 패키지와 분리한 제작자용 로컬 확장판에서만 유지합니다.

인디스쿨 운영진의 허가와 이용약관을 먼저 확인합니다. 허가 범위가 링크 제공과 요약에 한정된다면 자료 파일 자체를 복제하지 않고 게시글 링크와 짧은 요약만 보냅니다.

완성품을 바로 사용하고 싶은 독자는 이 원고의 QR 코드 또는 다음 GitHub 저장소로 이동하세요.

`https://github.com/now-chae/indischool-daily-lesson-agent`

저장소의 `README.md`는 완성 코드 설치·설정용이고, `docs/초보자용-설치안내.md`는 ZIP을 내려받은 뒤 실제로 실행하는 사람을 위한 안내입니다. 이 원고와 설치 안내를 서로 바꿔 읽지 않도록 문서의 목적을 분리해 두었습니다.
