# 주간학습안내 입력 경로 확장 설계

## 목표

학교 홈페이지에 주간학습안내를 올리는 사용자와, 파일을 컴퓨터 폴더에 직접 보관하는 사용자가 같은 에이전트를 사용할 수 있게 한다.

## 확정 설계

- `web` 방식은 기존처럼 설정한 학교 홈페이지에서 날짜에 맞는 게시물과 첨부파일을 찾는다.
- `local` 방식은 설정한 로컬 폴더의 파일을 계속 누적해서 보관한다.
- 로컬 파일명에 `YYYY-MM-DD` 날짜가 하나 이상 있어야 하며, 두 날짜가 있으면 그 사이의 주간으로 본다.
- 같은 날짜에 맞는 파일이 여러 개면 가장 최근에 수정된 파일을 선택한다.
- 원본 로컬 파일은 읽기만 하며 삭제하지 않는다. 처리를 위해 별도 다운로드 폴더에 복사한다.
- HWP·HWPX·JPG·JPEG·PNG·WEBP를 지원한다. 이미지 파일은 OpenAI Vision 키가 있을 때 자동 판독한다.
- 파일을 선택한 뒤의 과정(날짜·학년·반·시간표 검증, 검색어 생성, 인디스쿨 검색, 카카오 발송)은 두 방식이 공유한다.

## 사용자 흐름

1. 설치 중 `홈페이지` 또는 `로컬 파일 폴더`를 선택한다.
2. 홈페이지 방식은 주소를 입력한다.
3. 로컬 방식은 기본 폴더 `%LOCALAPPDATA%\\LessonAgent\\plans`를 사용하거나 다른 폴더를 입력한다.
4. 사용자는 매주 파일을 폴더에 추가하고, 파일명에 주간 시작일을 넣는다. 예: `2026-08-17_주간학습안내.hwpx`.
5. 예약 실행 시 실행 날짜와 파일명 날짜를 비교해 해당 주간 파일만 선택한다.

## 오류 처리

- 해당 날짜와 일치하는 로컬 파일이 없으면 `확인 필요` 메시지를 보낸다.
- 날짜 범위, 학년, 반, 1~6교시를 확인하지 못하면 인디스쿨 검색을 시작하지 않는다.
- 여러 파일이 일치하면 최신 수정 파일을 사용하고 실행 기록에 후보 목록을 남긴다.
