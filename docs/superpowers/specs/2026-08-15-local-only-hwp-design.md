# 로컬 주안 기본화 및 HWP/HWPX 판독 보강 설계

## 목표

공개 GitHub 패키지는 로컬 주간학습안내 파일을 기본 입력으로 사용하고, HWP/HWPX 표를 안정적으로 읽으며, 학교·학년·반을 설정값으로 처리하고, 기존 홈페이지 수집 코드는 제작자의 로컬 확장판으로 보존한다.

## 결정 사항

공개 저장소의 `plan_source`는 `local`만 지원한다. 설치 과정에서 사용자가 주안 폴더를 지정하고, 파일명에 포함된 날짜 범위로 오늘 사용할 파일을 고른다. `SchoolClient`와 홈페이지 URL 설정은 공개 runtime에서 제거한다.

기존 홈페이지 수집 코드는 현재 `packaging` 소스와 별도의 `local-only/indischool-web-mode-backup`에 보관한다. 이 백업은 GitHub에 커밋하지 않는다.

HWP는 `hwp5txt` 명령을 사용하는 어댑터로 읽고, 명령이 없거나 결과가 비어 있으면 설치 방법이 포함된 명확한 오류를 낸다. HWPX는 XML 문단을 단순 연결하지 않고 표의 행·열·셀 텍스트를 보존한 뒤 구조화된 주간 시간표와 학습내용으로 변환한다. 표 구조가 확정되지 않으면 검색하지 않는다.

모든 학년·반·제외 과목은 `Settings` 값으로 처리한다. Skill, 문서, 메시지 기본값에 특정 반을 고정하지 않는다.

## 데이터 흐름

```text
LESSON_AGENT_LOCAL_PLAN_DIR
        ↓
LocalPlanClient가 날짜 범위에 맞는 원본 선택
        ↓
HWP/HWPX 어댑터가 표 구조를 보존해 텍스트 레코드 생성
        ↓
parse_lessons가 설정한 학년·반·요일·순번 검증
        ↓
인디스쿨 검색·선별·요약
        ↓
카카오 나와의 채팅 전송
```

예약은 runtime의 기능이 아니라 Codex 예약 메뉴에서 실행 지시문으로 등록한다. 공개 패키지에는 Windows 작업 스케줄러를 기본 경로로 설명하지 않는다.

## 오류 처리

- 날짜에 맞는 로컬 파일이 없으면 파일 경로와 날짜를 포함한 `no_plan` 결과를 낸다.
- HWP/HWPX 확장자는 맞지만 표를 확정하지 못하면 `table_unreadable`을 낸다.
- 특정 과목 차시만 확정하지 못하면 다른 과목은 계속 처리하고 해당 과목에 `확인 필요`를 표시한다.
- 학년·반·요일의 전체 시간표가 확정되지 않으면 검색과 발송을 중단한다.

## 테스트 범위

실제 학교 HWP 파일은 개인정보와 학교 자료가 포함될 수 있으므로 저장소 fixture로 커밋하지 않는다. 대신 작은 HWPX 표 fixture와 문자열 기반 구조 레코드를 테스트한다. 사용자가 제공한 HWP는 로컬 스모크 테스트에서만 사용한다.

테스트는 로컬 파일 선택, 기본 설정, 표 행·열 추출, 설정 반 번호 대응, HWP 변환 명령 누락 오류, 하드코딩 없는 Skill 문서를 검증한다.

## 제외 범위

이번 변경에서는 인디스쿨 검색 알고리즘과 카카오 메시지 형식을 재설계하지 않는다. 홈페이지 수집 기능도 제거하지 않고 로컬 전용 백업으로만 보존한다.
