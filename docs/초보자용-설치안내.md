# 📘 초보자용 설치 안내

이 문서는 컴퓨터에 익숙하지 않아도 **복사 → 붙여넣기 → Enter** 순서로 따라 할 수 있게 작성했습니다.

이 문서는 GitHub에서 완성 코드를 내려받아 실제로 사용하는 사람을 위한 안내입니다. 에이전트를 Codex와 함께 처음부터 제작하려는 사람은 별도의 [초보자용 제작 원고](초보자용-제작원고.md)를 읽으세요. 제작 원고와 이 설치 안내는 목적이 다릅니다.

## 0. 먼저 확인할 것

이 프로그램은 Windows에서 실행됩니다. 설치 폴더는 OneDrive가 아닌 `C:\LessonAgent`를 사용하세요. 로그인 쿠키와 Chrome 임시 파일 때문에 OneDrive에서 수천 개 파일 삭제 경고가 나타날 수 있습니다.

## 1. ZIP 받기

1. GitHub 저장소를 엽니다.
2. 초록색 **Code** 버튼을 누릅니다.
3. **Download ZIP**을 누릅니다.
4. ZIP 파일을 `C:\LessonAgent`에 풉니다.

PowerShell을 열고 다음 두 줄을 실행합니다.

```powershell
cd C:\LessonAgent\indischool-daily-lesson-agent
Set-ExecutionPolicy -Scope Process Bypass
```

## 2. 설정 파일을 자동으로 만들며 설치하기

설치 명령은 프로그램만 설치하는 것이 아니라 사용자별 설정 파일도 함께 만듭니다. `setup.ps1`이 질문을 하나씩 보여 주면 답을 입력하세요. 실제 값은 프로젝트 폴더가 아닌 `%LOCALAPPDATA%\LessonAgent\config\.env`에 저장되므로 `.env` 파일을 직접 만들 필요가 없습니다.

저장소의 `.env.example`은 필요한 설정 이름을 보여 주는 예시일 뿐입니다. 실제 API 키를 `.env.example`에 쓰거나 GitHub에 올리면 안 됩니다. Kakao access token과 refresh token은 `.env`가 아니라 Windows 자격 증명 저장소에 보관됩니다.

```powershell
.\scripts\setup.ps1 -RegisterStartupSession
```

설치 중 질문이 나오면 다음처럼 입력합니다.

- 주간안내 파일을 넣을 폴더를 입력합니다. Enter를 누르면 기본 폴더를 사용합니다.
- 담당 학년은 예를 들어 `6`처럼 숫자만 입력합니다.
- 담당 반은 예를 들어 `2`처럼 숫자만 입력합니다.
- 제외할 전담 과목은 `체육,영어`처럼 쉼표로 구분합니다.
- Kakao REST API 키는 Kakao Developers에서 만든 앱의 REST API 키를 입력합니다.
- 주간안내가 이미지일 때만 OpenAI API 키를 입력합니다. HWPX 파일은 키 없이 읽을 수 있습니다. 구형 HWP는 설치 과정에서 `pyhwp`가 함께 설치됩니다.

## 3. 로컬파일 방식

설치 질문에서 지정한 폴더에 주간안내 파일을 계속 추가합니다. 공개 GitHub 패키지는 학교 홈페이지를 자동 탐색하지 않습니다. 기본 폴더는 다음입니다.

```text
C:\Users\내이름\AppData\Local\LessonAgent\plans
```

파일명에 주간 날짜를 넣어 주세요.

```text
2026-08-17_주간학습안내.hwpx
2026-08-24_2026-08-28_주간학습안내.hwp
6학년_게시용_8월18일 - 8월21일(1주).hwp
```

파일을 지우지 않아도 됩니다. 프로그램이 오늘 날짜와 맞는 파일을 골라 사용합니다. 날짜가 없는 파일은 사용하지 않습니다.

지원 파일: `.hwp`, `.hwpx`, `.jpg`, `.jpeg`, `.png`, `.webp`

구형 HWP는 설치 과정에서 `pyhwp`가 설치되며, 표가 있는 HWP는 `hwp5html`로 표 구조를 보존해 읽습니다. 설치가 막혀 도구가 없는 경우 실행 결과에 설치 필요 사유가 표시됩니다.

## 4. 인디스쿨 로그인

```powershell
.\scripts\start-indischool-session.cmd
```

전용 Chrome이 열리면 인디스쿨에 로그인합니다. 로그인한 뒤 창을 닫지 말고 최소화합니다. 매일 이 창이 열려 있어야 자동 검색이 가능합니다.

## 5. 카카오 연결

### 5-1. 리디렉션 주소 등록

Kakao Developers → 내 애플리케이션 → 카카오 로그인 → Redirect URI에 다음을 등록합니다.

```text
http://localhost:8765/callback
```

### 5-2. 인증 실행

```powershell
.\scripts\run.ps1 -SetupKakao
```

카카오 로그인 후 주소창에서 `code=` 뒤의 값을 복사해 PowerShell에 붙여넣고 Enter를 누릅니다.

### 5-3. 시험 메시지

```powershell
.\scripts\run.ps1 -TestKakao
```

카카오톡 **나와의 채팅**에 시험 메시지가 오면 성공입니다.

## 6. 실제 자료 찾기 시험

먼저 카카오톡으로 보내지 않고 결과를 확인합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26 -DryRun
```

화면에 표시된 시간표와 검색어가 맞으면 실제 발송을 합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26
```

## 7. Codex 예약 메뉴에 등록하기

이 프로젝트는 Windows 작업 스케줄러가 아니라 Codex 앱의 **예약 메뉴**에 등록해 매일 실행합니다.

1. Codex에서 이 작업 대화를 엽니다.
2. 예약 또는 Automations 메뉴에서 새 반복 예약을 만듭니다.
3. 다음 내용을 예약 지시문으로 입력합니다.

```text
이 저장소의 인디스쿨 수업자료 에이전트를 매일 오전 8시 40분(Asia/Seoul)에 실행해줘.
오늘 날짜의 주간학습안내를 확인하고, 체육·영어를 제외한 과목의 자료를 검색한 뒤,
과목·검색어·제목·링크·핵심요약을 카카오톡 ‘나와의 채팅’으로 보내줘.
판독이나 로그인 세션이 불확실하면 자료를 추측하지 말고 확인 필요와 이유를 보내줘.
```

예약 실행 시 주안 입력 방식과 인디스쿨 로그인 세션이 준비되어 있어야 합니다. 로컬 Chrome 세션에 연결하는 구현이라면 예약 실행 환경에서 전용 Chrome 프로필에 접근할 수 있는지도 확인하세요.

## 8. 자주 생기는 문제

### 로컬파일을 못 찾는 경우

1. 파일 확장자가 HWP/HWPX/이미지인지 확인합니다.
2. 파일명에 `2026-08-17`처럼 날짜가 있는지 확인합니다.
3. 설치 때 입력한 폴더가 맞는지 확인합니다.
4. 시험 명령에 날짜를 넣어 다시 실행합니다.

```powershell
.\scripts\run.ps1 -Date 2026-08-18 -DryRun
```

### 인디스쿨 로그인이 풀린 경우

```powershell
.\scripts\start-indischool-session.cmd
```

전용 Chrome에서 다시 로그인합니다.

### 카카오 인증이 풀린 경우

```powershell
.\scripts\run.ps1 -SetupKakao
```

### 자동 실행을 멈추는 경우

Codex 앱의 예약 메뉴에서 해당 예약을 해제합니다. 예약만 삭제되며 파일과 로그인 설정은 지워지지 않습니다.
