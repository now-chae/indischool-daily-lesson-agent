# 초보자용 설치 안내

이 프로그램은 매일 주간학습안내를 읽고, 오늘 수업에 맞는 인디스쿨 자료의 **제목·링크·한 줄 요약**을 카카오톡 `나와의 채팅`으로 보내는 Windows용 교사 보조 도구입니다.

인디스쿨 자료 파일을 다시 올리거나 판매하지 않습니다. 게시글 링크와 짧은 요약만 개인 채팅으로 전달합니다.

## 1. 준비물

- Windows 10 또는 11 컴퓨터
- Python 3.11 이상
- Google Chrome
- 인디스쿨 계정
- 카카오톡 계정
- 카카오 개발자 앱의 REST API 키

설치 폴더는 OneDrive 동기화 폴더가 아닌 `C:\LessonAgent` 같은 곳을 권장합니다.

## 2. 파일 받기

GitHub 페이지에서 `Code → Download ZIP`을 누르고 ZIP을 내려받습니다. ZIP을 `C:\LessonAgent`에 풀고 PowerShell을 엽니다.

```powershell
cd C:\LessonAgent\indischool-daily-lesson-agent
Set-ExecutionPolicy -Scope Process Bypass
```

## 3. 프로그램 설치

```powershell
.\scripts\setup.ps1 -RegisterStartupSession
```

질문에 다음처럼 답합니다.

- 학교 홈페이지: **근무 학교의 주간학습안내가 있는 주소**
- 학년: **담당 학년** (예: `6`)
- 반: **담당 반** (예: `2`)
- 제외할 전담 과목: **학교에 맞게 입력** (예: `체육,영어`)
- Kakao REST API 키: 카카오 개발자 콘솔의 REST API 키
- OpenAI API 키: 홈페이지 이미지 자동 판독을 사용할 때만 입력

설치 프로그램은 다음 위치를 사용합니다.

```text
%LOCALAPPDATA%\LessonAgent\config
%LOCALAPPDATA%\LessonAgent\indischool-profile
%LOCALAPPDATA%\LessonAgent\state
%LOCALAPPDATA%\LessonAgent\downloads
```

OneDrive에는 로그인 쿠키나 실행 캐시를 저장하지 않습니다.

## 4. 인디스쿨 로그인

설치가 끝나면 전용 세션 창을 엽니다.

```powershell
.\scripts\start-indischool-session.cmd
```

열린 Chrome 창에서 인디스쿨에 직접 로그인합니다. 로그인 후 창을 닫지 말고 최소화해 두면 됩니다. 처음 한 번만 로그인하면 이후에는 저장된 세션을 사용합니다.

세션이 만료되면 같은 명령을 다시 실행해 로그인합니다.

## 5. 카카오 연결

1. Kakao Developers에서 앱을 만듭니다.
2. 카카오 로그인과 메시지 사용 동의항목을 활성화합니다.
3. 카카오 로그인 리디렉션 URI에 다음 주소를 등록합니다.

```text
http://localhost:8765/callback
```

4. PowerShell에서 실행합니다.

```powershell
.\scripts\run.ps1 -SetupKakao
```

브라우저에서 카카오 로그인을 승인한 뒤, 주소창의 `code=` 뒤 값을 PowerShell에 붙여넣습니다.

연결 시험:

```powershell
.\scripts\run.ps1 -TestKakao
```

카카오톡 `나와의 채팅`에 시험 메시지가 오면 성공입니다.

## 6. 시험 실행

실제 발송 없이 시간표와 검색어만 확인하려면 다음처럼 실행합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26 -DryRun
```

결과가 올바르면 실제 실행은 다음처럼 합니다.

```powershell
.\scripts\run.ps1 -Date 2026-06-26
```

## 7. 매일 자동 발송 등록

```powershell
.\scripts\install-task.ps1
```

Windows 작업 스케줄러에 매일 오전 8시 40분 작업이 등록됩니다.

현재 버전은 다음 조건이 필요합니다.

- PC 전원이 켜져 있을 것
- Windows 사용자 계정이 로그인되어 있을 것
- 인터넷이 연결되어 있을 것
- 인디스쿨 전용 Chrome 세션이 실행 중일 것

## 8. 자주 생기는 문제

### `session_browser_missing`

전용 Chrome 세션이 닫힌 상태입니다.

```powershell
.\scripts\start-indischool-session.cmd
```

### 인디스쿨 로그인 필요 메시지

세션이 만료된 것입니다. 전용 Chrome에서 다시 로그인합니다.

### 카카오 재인증 필요 메시지

다시 실행합니다.

```powershell
.\scripts\run.ps1 -SetupKakao
```

### 오늘 자료가 오지 않음

먼저 다음 명령으로 오류를 확인합니다.

```powershell
.\scripts\run.ps1 -DryRun
```

날짜·시간표 판독이 불확실하면 잘못된 자료를 보내지 않고 `확인 필요`만 표시하도록 되어 있습니다.

## 9. 삭제

예약 발송만 중지하려면:

```powershell
.\scripts\remove-task.ps1
```

이 명령은 작업 스케줄러 등록만 삭제합니다. 로그인 세션과 설정을 완전히 지우려면 Windows 설정 폴더에서 다음 폴더를 직접 확인한 뒤 삭제합니다.

```text
%LOCALAPPDATA%\LessonAgent
```

삭제 전 카카오 인증을 포함한 다른 LessonAgent 설정이 없는지 확인합니다.
