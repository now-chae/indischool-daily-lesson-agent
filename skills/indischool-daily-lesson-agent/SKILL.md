# 인디스쿨 오늘 수업자료

## 역할

주간학습안내에서 백석초등학교 6학년 2반의 당일 수업을 확인하고, 체육·영어를 제외한 과목의 허가된 인디스쿨 자료를 찾아 카카오톡 `나와의 채팅`으로 간결하게 전달한다. 실제 브라우저 자동화와 인증은 패키지의 로컬 실행기를 사용한다.

## 실행 전 확인

1. 설치가 안 되어 있으면 패키지 루트의 `scripts/setup.ps1`을 먼저 실행하도록 안내한다.
2. 인디스쿨 인증은 `scripts/start-indischool-session.cmd`로 열린 전용 Chrome에서 사용자가 직접 완료하게 한다.
3. 카카오 인증정보·비밀번호·쿠키를 대화나 로그에 요구하거나 기록하지 않는다. 카카오 OAuth는 `lesson-agent setup-kakao`로 사용자가 직접 완료한다.
4. 인디스쿨 운영진의 허가 범위를 벗어난 자동 접근은 수행하지 않는다. 허가 전에는 사용자가 직접 찾은 링크를 정리하는 보조 모드만 사용한다.

## 당일 처리 순서

1. 원본 주간학습안내를 확대해 날짜 범위와 2반의 해당 요일 1~6교시를 먼저 확정한다.
2. 월요일부터 누적한 과목별 등장 순번과 학습내용 행을 대응한다. 차시명은 글자 단위로 두 번 대조하고 추측하지 않는다.
3. 체육·영어 및 전담 과목은 제외한다.
4. 검색어를 만든다.
   - 괄호 속 차시 수와 활동 동사는 제거한다.
   - 국어 읽기·쓰기 차시는 핵심 명사를 붙여 검색한다. 예: `견학 기록문 읽기 (1/2)` → `견학기록문`.
   - `마무리하기`, `복습`, `총정리`, `스스로 하기`처럼 일반적인 차시는 주간안내의 단원명과 `복습`, `총정리`, `마무리` 조합을 각각 검색한다.
   - 수학·과학은 중심 개념어와 보조 핵심어를 분리한다. 제목에 두 요소가 모두 있는 자료를 최우선으로 고르고, 다른 단원의 대형 모음글은 제외한다. 제목 후보가 없을 때만 본문을 보조 확인한다.
   - 음악은 차시 수를 뺀 활동 제목 전체를 검색한다.
   - 사회·도덕은 중심 개념과 행동어를 분리하고, 행동어가 제목 또는 본문에 있는 자료를 좋아요순으로 우선한다.
   - 미술은 차시가 서로 다른 연차시면 검색어도 분리한다. 관련 자료 2건과 최근 인기 자료 3건을 제공하며 기간은 7·14·21·28일 순서로 필요한 만큼만 늘린다.
5. 검색 결과가 0건이면 같은 검색어를 최대 3회 재조회한다. 날짜·시간표 판독이 불확실하면 전체 전송을 중단하고 이유만 알린다. 특정 과목만 불확실하면 확정된 과목은 전송하고 해당 과목에는 실제 검색어와 확인 필요 사유를 남긴다.
6. 메시지는 다음 형식으로 짧게 작성한다.

```text
📚 과목: 수학
🔎 검색어: 소수의 나눗셈
📝 제목: 게시글 제목
🔗 링크: https://indischool.com/...
💡 핵심요약: 한 문장 요약
⚠ 확인사항: 필요한 경우에만 작성
```

## 로컬 실행 규칙

- 인디스쿨 Chrome 프로필은 `%LOCALAPPDATA%\LessonAgent\indischool-profile`에 둔다.
- 실행 상태와 임시 다운로드는 각각 `%LOCALAPPDATA%\LessonAgent\state`, `%LOCALAPPDATA%\LessonAgent\downloads`에 둔다.
- OneDrive 안에 인증 프로필·캐시·토큰을 만들지 않는다.
- 정기 실행은 Windows 작업 스케줄러의 오전 8시 40분 작업으로 등록한다. PC가 켜져 있고 Windows 사용자가 로그인되어 있어야 한다.
